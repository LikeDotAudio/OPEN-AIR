# OPEN-AIR Python dependencies.
#
# Python is glue here, not the product: the instrument probe path and the
# discovery/deploy tooling. Everything else is Rust and TypeScript. That is why
# this lives in Deployment/ rather than the repo root — the root is reserved for
# files a tool can only find there (pnpm workspace, rustup pin, .nvmrc).
#
#   pip install -r Deployment/requirements.txt
#
# There are TWO requirements files and they are not duplicates:
#   Deployment/requirements.txt        — this one; running the system
#   Deployment/requirements-deploy.txt — the FTPS deploy script only
# Keep the paho-mqtt bound identical in both; the deploy script and the
# discovered-GUI builder both import it.

# --- Instrument control (REQUIRED for VISA discovery) -------------------
# The orchestrator shells out to `python3 -c "import pyvisa ..."` to probe
# *IDN? and to run live SCPI writes/queries. It requests the pure-Python
# backend explicitly — ResourceManager('@py') — so pyvisa-py is NOT
# optional; without it every instrument probe fails and the Discovered tab
# comes up empty.
pyvisa>=1.11
pyvisa-py>=0.5

# --- MQTT (REQUIRED for the discovered-GUI builder) --------------------
# Deployment/build_discovered_gui.py subscribes to the retained discovery
# topics and writes the Discovered tab panels. It branches explicitly on the
# paho major version (mqtt.CallbackAPIVersion.VERSION2 for 2.x, bare
# mqtt.Client() for 1.x — build_discovered_gui.py:205-207), so 3.x is
# untested and excluded. Upper bound matches Deployment/requirements-deploy.txt.
paho-mqtt>=1.6,<3

# --- Protocol test harnesses (TESTS/Protocols/*) ------------------------
# Not needed to RUN OPEN-AIR, but every one of these is imported by a
# harness that ships in the repo, so `pip install -r requirements.txt`
# followed by running any protocol tester used to fail on ImportError.
# Install with the app; they are small and pure-Python except rtmidi.
zeroconf>=0.100          # dnssd_tester.py, mdns_tester.py
requests>=2.28           # nmos_tester.py, rest_tester.py
python-osc>=1.8          # osc_tester.py  (imports as `pythonosc`)
websocket-client>=1.5    # websocket_tester.py  (imports as `websocket`)
mido>=1.3                # midi_tester.py
python-rtmidi>=1.5       # mido's default backend; needs a C toolchain

# --- OS packages (NOT installable by pip) -------------------------------
# Install these with your system package manager:
#   mosquitto             # the MQTT broker — nothing works without it
#   mosquitto-clients     # mosquitto_sub/pub, the documented debug path
#   python3-tk            # tkinter, used by TESTS/Protocols/osc/osc_monitor.py
#   libasound2-dev        # ALSA headers, needed to build the midir crate
#
#   Debian/Ubuntu:
#     sudo apt-get install mosquitto mosquitto-clients python3-tk libasound2-dev

# --- Optional -----------------------------------------------------------
# pyvisa-py can use these for extra transports; not needed for the

#   pyserial>=3.5      # serial (ASRL) instruments
