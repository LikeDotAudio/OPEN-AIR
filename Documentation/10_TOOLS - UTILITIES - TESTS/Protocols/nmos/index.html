Registry Endpoints (IS-04)

Registration API

Handles the discovery and registration of Nodes and their resources. Devices POST their capabilities here.

http://localhost:3210/x-nmos/registration/v1.3
Port 3210

Query API

Allows controllers to browse the registry. Clients can fetch the registry tree, or subscribe to WebSockets for real-time delta updates.

http://localhost:3211/x-nmos/query/v1.3
Port 3211

Mock Device Endpoints

Node API (IS-04)

Hosted on the nodes themselves to expose their underlying capabilities and topology. Used for peer-to-peer exploration.

http://localhost:3300/x-nmos/node/v1.3
Port 3300

Connection API (IS-05)

Provides the mechanism to connect senders and receivers together using SDP files and multicast parameters.

http://localhost:3300/x-nmos/connection/v1.1
Port 3300

Channel Mapping (IS-08)

Allows routing and re-mapping of audio channels within the active flows on the device.

http://localhost:3300/x-nmos/channelmapping/v1.0
Port 3300

Events API (IS-07)

Event and Tally streaming. Subscribes to boolean or quantitative states on the network (e.g. Tally Lights).

http://localhost:3300/x-nmos/events/v1.0
Port 3300

Control Protocol (IS-12)

WebSocket endpoint for real-time control of device properties (Gain, Mute, Matrix routing, etc).

ws://127.0.0.1:3302/x-nmos/ncp/v1.0
Port 3302 (WS)
