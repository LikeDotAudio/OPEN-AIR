WebSocket (RFC 6455) - Transmitter Specification

Overview

This document outlines the requirements for a standalone, open-source Transmitter (Generator) for testing purposes.

Requirements

A successful WebSocket Transmitter (Client) must perform the HTTP Upgrade handshake, properly frame messages (text/binary), and respond to Ping/Pong control frames.
