Changelog — 2026-07-03

Meters, faders & metering zoo

Middle-click random test (restored)

  • Middle-clicking a VU/needle meter or a bar graph now jumps it to a random valid value within the domain (snapped to step) so ballistics can be eyeballed. Shared handler in frameLayout/FieldComponent.jsx (onMouseDown, button 1), wired onto the VU-knob, needle, and bar-graph wrappers.

Needle meter — fit-guard for shape cutouts

  • libControl/metering/NeedleMeter.jsx: added a fit-guard that clamps the pivot inside the bezel interior and caps the arc radius so the dial/needle can't be clipped by the shape cutout (was happening on tall-origin shapes like squircle/squectangle in near-square per-shape zoo cards). No-op when the gauge already fits, so the wide "All" grid is unchanged.

Horizontal Bar meter zoo — row spacing

  • frameLayout/OcaBlock.jsx now honors row_spacing / column_spacing (node-level or under layout, default 0). Set row_spacing: 28 on the Horizontal bar demo block so the stacked bars stop overlapping.

New metering zoo elements

  • Added 9_Zoo/2_Metering/6_EQ/EQ.json (_Equalization) and 9_Zoo/2_Metering/7_Dynamics/Dynamics.json (_AudioDynamics).

Composite widgets — demo cherry-picks

  • MDP (libControl/special/MDP/MDP.jsx, the active window.MDP): free-move selection glow, scroll-wheel intensity (native non-passive), 50%-crossing haptic detent, and the extended rotary needle now only shows while intensity is being adjusted.
  • CMDP (libControl/special/CMDP/CMDP.jsx): rewired into the demo's multi-channel circular display — per-channel faders from config.channels[], group coloring/visibility from group_configs[], segment hit-testing, perimeter labels, center hub, and onChange publishing the updated channels.
  • LTP (libControl/faders/LTPFader/LTPFader.jsx): cap drawn directly on the canvas (linear travel + rotation as one control), ±135° indicator, double-click pan-latch, freestyle mode, wheel fine-tune.
  • Bumped ?v= cache-bust for CMDP/MDP/LTPFader in index.html.

CMDP grouping/editing element (new)

  • Added libControl/special/CMDP/CMDPEditor.jsx (window.CMDPEditor, type _CMDPEditor) — a DOM panel to edit the CMDP's groups (colour, rename, visibility, solo, mute, add/remove) and channels (rename, group reassignment, level/depth/angle, visibility, mute, add/remove). Publishes the full { channels, group_configs } state.
  • Sync: FieldComponent now honors an explicit topic / shared_topic override so sibling widgets can share one MQTT state key. CMDP now reads value.group_configs, publishes group_configs alongside channels, rebuilds on external value changes (guarded against mid-drag), and seeds the shared topic on mount. The CMDP zoo places the editor beside the CMDP on the shared topic audio/cmdp/1 (2-column layout), so edits live-update the display.

Meter ballistics — decay to floor

  • NeedleMeter and MeterBarGraph now use peak-hold-release ballistics: a new sample latches a peak the needle/bar attacks up to, then it falls back to the floor (min) at the designated release_ms rate instead of holding the value — pairs with the middle-click test (jump, then decay to rest).

Crafty Knobs — Pan and Spread Variants

  • Crafty.jsx: Added new "pan" and "spread" variants for both spoked and led_ring styles.
    • spoked_pan / led_ring_pan: Visually indicates panning relative to center (0° / 12 o'clock).
    • spoked_spread / led_ring_spread: Visually indicates bidirectional spread outward from center.
  • Crafty.json: Added the four new Crafty Knob variants to the Zoo and updated layout to 5 columns.

Removed: Edit Detector

  • The Edit Detector metering component was removed (files, the _EditDetector dispatch branch, and its index.html script tag) at the user's request. The section below is retained for history only.

New metering component: Edit Detector (LCARS / Okudagram) — REMOVED

  • Added FrontEnd/libControl/metering/EditDetector/EditDetector.jsx — a new video "edit" meter. It averages the luminance of the selected input each frame (Rec.709 luma from a 160×90 sampling canvas) and flags a large frame-to-frame jump as an edit (a cut / scene change), appending each one to a time-stamped Edit Log (HH:MM:SS.mmm, direction, Δ%, luma from→to).
  • Input source and view presets are two visually separated LCARS button groups (per request):
    • SOURCE — TEST PATTERN (standard SMPTE 75% colour bars, drawn on a canvas), CAPTURE TAB (getDisplayMedia, real pixels + audio), LOAD FILE (local video), URL field + LOAD URL (CORS .mp4/.webm). Whichever is selected is the analyzed input.
    • PRESETS — DEFAULT / AUDIO / ALL VIDEO / COLOUR / LUMA layouts, plus a separate SENS group (SUBTLE / NORMAL / HARD) for the detector's own sensitivity threshold. LAYOUT button top-right resets to DEFAULT.
  • Meter panels (preview, luminance, colour R/G/B, audio RMS, edit log): each has a ⤢ expand button; double-clicking a panel restores the regular multi-panel view.
  • Styled in the LCARS/Okudagram aesthetic (black field, rounded pill buttons, coloured group elbows, condensed uppercase type).
