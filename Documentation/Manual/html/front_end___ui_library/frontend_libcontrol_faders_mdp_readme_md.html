MDP — Multi Dimensional Panner (faders variant)

Multi-axis controller (X, Y, linear, rotation) with free placement on a canvas.

  • Defines (global): MDP
  • Props: config, value, onChange

Note: the live app loads the panner at ../../special/MDP/MDP.jsx, not this file. This faders/MDP copy is currently not referenced by frontEnd/Core/Launch/index.html (older/duplicate variant); both define the same MDP global, so do not load both at once.
