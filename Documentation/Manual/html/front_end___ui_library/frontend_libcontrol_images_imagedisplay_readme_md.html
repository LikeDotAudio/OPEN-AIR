ImageDisplay — image panel

Shows an image (path from value or config.value_default) with an optional label.

  • Defines (global): ImageDisplay
  • Props: value (image path), config (label/label_active, geometry.width/height)
  • Loaded by: the live app via frontEnd/Core/Launch/index.html.
