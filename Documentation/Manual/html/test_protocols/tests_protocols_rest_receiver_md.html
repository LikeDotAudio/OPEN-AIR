REST (Representational State Transfer) - Receiver Specification

Overview

This document outlines the requirements for a standalone, open-source Receiver (Mock Device) for testing purposes.

Requirements

A successful REST Receiver (Server) must expose a stateless API, handle standard HTTP verbs, provide appropriate HTTP status codes (200, 400, 404, 500), and serialize JSON.
