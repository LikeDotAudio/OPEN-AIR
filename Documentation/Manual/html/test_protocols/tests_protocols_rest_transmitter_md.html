REST (Representational State Transfer) - Transmitter Specification

Overview

This document outlines the requirements for a standalone, open-source Transmitter (Generator) for testing purposes.

Requirements

A successful REST Transmitter (Client) must construct valid HTTP GET/POST/PUT/PATCH/DELETE requests, handle headers (Content-Type, Auth), and parse JSON responses.
