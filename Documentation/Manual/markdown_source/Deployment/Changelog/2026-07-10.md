# 2026-07-10

## Pattern Sequencer — 16 tracks, patterns library, MQTT-backed state

`FrontEnd/libControl/special/Sequencer/Sequencer.jsx`

- **16 tracks** (was 4). Track count is now data-driven from a single `TRACKS`
  list — each entry has `{ name, freq, type }` (Kick, Snare, Hi-Hat, Perc, Clap,
  Rim, Tom Lo/Mid/Hi, Cymbal, Ride, Cowbell, Conga, Clave, Shaker, FX). The pitch
  lookup, the render loop, and the pattern-state length all derive from it, plus a
  `STEP_COUNT` constant for the 16 steps. Changing the count now means editing one
  list.
- **Shrunk the grid** so 16 rows fit: step cells 24×32→18×20 px, row gap 8→3 px,
  tighter step gap/padding, smaller container padding and header.
- **Patterns Library**: Save (names the current grid + tempo), one-click load, and
  per-entry delete, rendered below the grid. Save overwrites an entry of the same
  name.
- **MQTT-backed**: both the live sequence and the library now push to and read from
  MQTT via `useMqttState` on retained topics:
  - `OpenAir/Gui/Sequencer/<label>/pattern` — `{ grid, bpm }`
  - `OpenAir/Gui/Sequencer/<label>/library` — `{ items: [...] }`
  Retained payloads mean state survives reloads and syncs to any other client
  viewing the same sequencer. localStorage still seeds the library so it loads with
  the broker offline. No `nodeJson` is passed, so an empty first mount never
  clobbers a retained pattern.

## Drum machine: shared kit across Sampler ⟷ Sequencer ⟷ Wave editor

Unified drum-sound layer so the Sampler pads, Sequencer tracks, and Wave editor
share one 16-voice kit and one sample store.

- **New `libControl/special/DrumKit.js`** — `OA_DRUM_KIT` (16 named voices), a
  shared `AudioContext` (`oaAudioCtx`), the sample store
  `OA_DRUM_SAMPLES[idx] = { buffer, pitch, loop, fade, name }`, and helpers
  `oaSetDrumSample` / `oaUpdateDrumSample` / `oaPlayDrumSample` / `oaPlayDrumVoice`
  / `oaTriggerDrum` (sample-or-synth, honours pitch/loop/fade; auto-loop pads
  toggle via `OA_DRUM_LOOPS`). The Sequencer's `TRACKS` now come from this kit.
- **Sampler**: pad names from the kit; velocity→volume; **ALT+click** loads a
  sample; pads 120px; **transient glow** scaled to velocity that fades over the
  sound's length (`@keyframes oaPadGlow`).
- **Sequencer**: plays a pad's loaded sample (pitch/fade) or synth; selectable
  length **4/8/16/32/64**; **per-track MUTE** (keeps the pattern).
- **Wave editor**: **zoom** (wheel/±/Sel/Fit); **cursor** + **I/O/F** keys
  (in/out/fade) with a playhead; **Assign to Pad** slices the selection (with
  **Auto-loop** and **Fade**); **Captured Samples** list; **Pitch wheel**
  (−12..+12 st) on the selected pad.

`index.html`: added `DrumKit.js`; bumped AudioEditor v2, Sequencer v4, Sampler v5.
