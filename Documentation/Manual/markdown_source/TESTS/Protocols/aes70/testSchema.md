# AES70 (OCA - Open Control Architecture) - Test Schema

## Framework
This schema defines the integration test boundary between the standalone testing tools and the OPEN-AIR core.

Test Schema: 
1. Discoverability check (mDNS).
2. Connection establishment (OCP.1).
3. Object model enumeration (GetClassIdentification).
4. Parameter mutation (SetGain, SetMute).
5. Subscription verification (verify notifications on mutation).
