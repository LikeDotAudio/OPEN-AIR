# DNS-SD (DNS Service Discovery) - Transmitter Specification

## Overview
This document outlines the requirements for a standalone, open-source Transmitter (Generator) for testing purposes.

## Requirements
A successful DNS-SD Transmitter (Advertiser) must construct and broadcast valid Multicast DNS PTR, SRV, and TXT records conforming to RFC 6763, correctly responding to probing and query requests on port 5353.
