# SNMP (Simple Network Management Protocol) - Test Schema

## Framework
This schema defines the integration test boundary between the standalone testing tools and the OPEN-AIR core.

Test Schema: 
1. ASN.1 BER encoding/decoding.
2. MIB tree walking (GETBULK/GETNEXT).
3. SNMPv3 Authentication/Privacy.
4. Trap generation and reception.
