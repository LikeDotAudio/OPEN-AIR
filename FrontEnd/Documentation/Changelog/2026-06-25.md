# Changelog — 2026-06-25

## Quiet launcher build output

- **Changed** `openair.py` `build_rust()` to capture cargo's output and print it
  only when a build **fails**. The ~19 k characters of benign warnings (unused
  imports, dead code, and `non_snake_case` on the pyo3 module exports — whose
  names must match the Python import, so they can't be renamed) no longer flood
  the console on every launch. Build **errors** still surface in full. Set
  `OPENAIR_VERBOSE_BUILD=1` to stream the full output (warnings included).

## Verified: MQTT GUI topic tree migration

- **Verified** the folder-hierarchy topic change live on the broker after launch.
  Widgets now publish e.g.
  `OpenAir/Gui/Spectrum/Instrument/frequency/Frequency/center_freq_MHz`
  (1073 `OpenAir/Gui` topics; top branches `Spectrum`, `scan`, `Zoo`, `Commands`,
  `Protocals`, `Control_Buttons`).
- **Confirmed** no stale flat topics remain (`Spectrum_YAK_N9340B_*`, `Migrated_*`,
  `Console_1-8`, `Router_Switcher_*`, `Oscilloscope_Instrument_*` → count 0); they
  cleared on the broker restart, so no retained-topic cleanup was needed.
