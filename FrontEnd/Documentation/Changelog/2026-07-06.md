# Changelog — 2026-07-06

## Equalization — configurable FIR export

`libControl/graphing/Equalization/Equalization.jsx`

### Export toolbar (dropdowns)
- Replaced the two in-chart echarts buttons ("Export FIR" / "Export CSV") with an
  HTML toolbar above the graph. CSV export is unchanged in output.
- **Export FIR** is now parameterised by four dropdowns, exactly the DSP knobs the
  frequency-sampling method needs:
  - **Taps** — 512 / 1024 / 2048 / 4096 / 8192 / 16384 (filter length).
  - **Sample Rate** — 44.1 / 48 / 88.2 / 96 / 192 kHz (target `fs`; also feeds the
    HP/LP digital biquad so the exported curve matches the destination rate).
  - **Phase** — `Linear` (symmetric taps, N/2 latency) or `Minimum` (real-cepstrum
    reconstruction, no pre-ringing, analog-like).
  - **Window** — Hann / Hamming / Blackman / Kaiser(β=8) / Rectangular.
  - Defaults (1024 / 48 kHz / Linear / Hamming) reproduce the previous hardcoded
    export.

### DSP engine
- Added module-scope helpers shared by the live curve and the export:
  `_fft` (in-place iterative radix-2 FFT/IFFT), `_besselI0`, `_windowVal`, and
  `generateFIR(bands, {taps, sampleRate, phase, window})`.
- `getBiquadGainDB` hoisted to module scope (was defined inline in the MQTT
  effect); gained an `fs` parameter (default 48000) so the export can sample the
  target magnitude at the chosen rate. The live curve calls it unchanged.
- Linear-phase path: target magnitude → IFFT → circular shift to center →
  symmetric window. Minimum-phase path: log-magnitude → cepstrum → causal fold →
  exp → IFFT → tail-only taper. This replaces the old fixed 1024-tap O(N²) DFT,
  so 8k/16k-tap exports are now fast.
- Latest `bands` and `totalData` are stashed in refs each effect run so the HTML
  export buttons never read a stale closure.

### Verification
- Standalone Node checks on the extracted DSP: flat EQ → linear unit impulse at
  center and minimum-phase delta at n=0; a +12 dB / Q2 peak at 1 kHz reconstructs
  to |H(1k)|≈+12 dB, |H(100)|≈0 dB, DC≈unity, with minimum-phase energy centroid
  ~3 vs linear ~1024. Full file transpiles under `@babel/preset-react`.
