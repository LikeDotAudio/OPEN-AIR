# 2026-07-11

## Sample Analyzer — Flatten/Rename tab: sorting, prefixes, dedup, tie-breaks

`Sample Analysis/rename_tab.py`

- **Defaults**: source dir `~/Documents/Music Samples`, destination
  `~/Documents/Renamed Samples` (created on startup so the preview routes into it),
  and **COPY** (keep originals) is now on by default.
- **Second sort level**: "Sort into subfolders by *Group* then *Subgroup*". A
  redundant second level is stripped — `Loop/"Loop Guitar"` → `Loop/Guitar`,
  `Loop/Loop` → `Loop` (the group name is removed from the subgroup folder).
- **Append `###BPM`** before the extension for any file with a real tempo
  (`bpm > 10`), not just loops.
- **Prepend** `group`, `group - subgroup`, or `group - subgroup - timbre` to file
  names; the group is stripped out of the subgroup so `Snare - Snare Medium`
  collapses to `Snare - Medium`.
- **Remove repeated words**: case-insensitive prefix/stem dedup splitting on
  ` - `, `_`, space and `-`, so `Snare - Snare Medium - … - Snaredrums - SNAREDRUM_054`
  → `Snare - Medium - … - 054` while keeping trailing disc numbers
  (`BASSDRUM - Bassdrum-01` keeps the `01`).
- **Sortable columns** (click any header) via a numeric-aware `_tv_sort`.
- **Duplicate names are auto-numbered, not errored**: two files that reduce to the
  same name get `-2`, `-3`, … so each target stays unique. The old red "name clash"
  is now a neutral **"Note" → auto-numbered** (muted blue), counted as a normal
  rename.

## Sample Analyzer — split the monolithic GUI + Rust core into modules

- **Python GUI** (`sample_analyzer_app.py`, was one 1300-line class) → one mixin per
  tab: `graph_tab.py` (3D cloud), `groups_tab.py`, `examiner_tab.py`,
  `guess_tab.py`, `rename_tab.py`, plus `config.py` for shared constants.
  `AnalyzerApp` composes the mixins; the shell keeps only state, the analysis
  subprocess, and playback.
- **Rust core** (`sample_analyzer_rs/src/main.rs`, was 940 lines) → 23 one-purpose
  modules: `peak`, `normalize`, `categorize` (+tests), `wav`, `acid`, `amplitude`,
  `pitch`, `spectrum`, `transients`, `sustain`, `timbre`, `label`, `analyze`
  (thin orchestrator), `feature_vec`/`sqdist`/`kmeans`/`cluster`, and
  `args`/`discover`/`sidecar`/`stream`/`emit`/`run`. The 247-line `analyze` and
  130-line `main` are now linear sequences of named single-purpose calls.

## Sample Analyzer — classifier taxonomy overhaul

`sample_analyzer_rs/src/categorize.rs`, `label.rs`

- **Full-path analysis**: classification now reads folder names + filename, so
  `Congas/01.wav` → Perc/Conga and `Drums/mystery.wav` → Unclassified/Drum from the
  folder alone.
- **Perc** is a parent group with curated subgroups: Block, Bongo, Conga, Shaker,
  Clave, Cowbell (the last four moved out of being their own top-level groups).
- **Keyboards** (new group) → Synth, Piano, Electric Piano, Organ, Clav, Keys.
- **DJ** (new group) → scratch / turntable / `dj`.
- **Loops/Patterns** (renamed from `Loop`) → Beat / Groove / Loop subgroups.
- **Unclassified** (renamed from `Other`); generic "drum" → subgroup **Drum**.
- **808** is a drum machine, not bass → `808 hh` = HiHat; **kik** → Kick.
