# SMPTE ST 2138 (Protobuf Interface) - Transmitter Specification

## Overview
This document outlines the requirements for a standalone, open-source Transmitter (Generator) for testing purposes.

## Requirements
A successful SMPTE 2138 Transmitter must serialize data into the ST 2138 Protocol Buffer schema, construct the gRPC/TCP transport layer, and handle streaming/unary RPCs.
