# YAK (OPEN-AIR Command Translation) - Test Schema

## Framework
This schema defines the integration test boundary between the standalone testing tools and the OPEN-AIR core.

Test Schema: 
1. UI-to-YAK mapping accuracy.
2. YAK-to-Hardware execution (SCPI validation).
3. State Mirroring latency.
4. Bidirectional state sync (Hardware -> UI).
