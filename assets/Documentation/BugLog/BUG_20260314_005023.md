# Bug Log: Reliability & Debugging Overhaul (2026-03-14)

## Issue
Distilled faults from system execution logs:
1. **Critical**: UI crashes with `ValueError: unknown color specifier: ''` when hovering over certain buttons.
2. **High**: Log spam with `name 'router_verbose_logging_enabled' is not defined` during every message ingest.
3. **Moderate**: VISA discovery encountering `wrong xid in reply` desync errors on multi-port gateways.

## Root Cause
1. **UI Crash**: `button_canvas_base.py` was passing raw configuration strings directly to PIL's `ImageColor.getcolor()`. Empty strings `""` in JSON layout files were not sanitized.
2. **Log Spam**: A documentation update mistakenly replaced `router_verbose_logging_enabled` with `LOCAL_DEBUG` in the module definition but left one reference in the logic loop.
3. **VISA Desync**: Concurrent network probes to the same gateway IP address caused VXI-11 RPC ID (XID) collisions.

## Resolution
1. **Sanitization**: Implemented `_get_color()` helper in `button_canvas_base.py` with a safe fallback to `#2b2b2b` for empty or NULL inputs.
2. **Flag Alignment**: Corrected the logic loop in `protocol_router.py` to use the standardized `LOCAL_DEBUG` flag.
3. **Concurrency Control**: Implemented a per-IP mutex registry (`_IP_LOCKS`) in `manager_visa_Search.py` to ensure only one probe hits a specific gateway at a time. Reduced `VISA_TIMEOUT` to 1000ms to improve discovery speed on dead networks.

## Verification
- **UI**: Hovering over buttons no longer triggers `ValueError`.
- **Router**: Log spam ceased; ingest throughput restored.
- **VISA**: Discovery successfully probes `HEWLETT-PACKARD,34401A` on gateway `44.44.44.111` without XID errors.
