# Bug Report: Massive Naming and Containerization Refactor

**Date:** 2026-03-16 01:00:00
**Priority:** 2 (Architectural/Standardization)
**Impact:** Significantly improved codebase maintainability, reduced cognitive load for developers, and eliminated redundant code paths.

## Issue
The project suffered from several naming and organizational violations:
1.  **Deep Redundancy**: Folders in `display/` often contained subfolders with identical names.
2.  **Flat Directories**: `workers/builder` contained over 50 widget folders in a single flat list.
3.  **Noise Prefixes**: Many files used redundant prefixes like `gui_` or `showtime_`.
4.  **Divergent Copies**: Critical files like `config_reader.py` and `hidden_breakoff.py` had multiple versions.

## Root Cause
Evolutionary "cruft" from rapid prototyping and a lack of strict containerization standards during the early development phases.

## Resolution
1.  **Flattened `display/`**: Removed recursive folder naming (e.g., `0_Australia/0_Australia`).
2.  **Containerized Widgets**: Moved all `workers/builder` widgets into categorical subfolders (`widgets/buttons`, `widgets/faders`, etc.).
3.  **Removed Noise**:
    *   Renamed `gui_*.json` to `*.json` in the `display/` tree.
    *   Renamed `showtime_*` to `*` in `workers/Showtime/`.
    *   Updated `LayoutParser` and `ModuleLoader` to support prefix-less discovery.
4.  **Consolidated Sources of Truth**:
    *   Deleted legacy `config_reader.py` in `workers/Command_Router/mqtt/setup/`.
    *   Deleted redundant `hidden_breakoff.py` in `managers/Display/`.
    *   Merged `Mqtt` and `mqtt` directories.

## Verification
1.  **Discovery**: Verified that `WidgetRegistry` still discovers all 51 widget types via recursive scanning.
2.  **Imports**: Updated and verified imports in `launcher.py`, `builder.py`, and `workers/Showtime/`.
3.  **GUI Logic**: Updated `LayoutParser` and `ModuleLoader` to ensure JSON and Python GUI files are correctly identified without the `gui_` prefix.
