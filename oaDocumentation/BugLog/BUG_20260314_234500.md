# Bug Report: UI Startup Crash and Protocol Dispatch AttributeError

**Date:** 2026-03-14 23:45:00  
**Priority:** 1 (Critical/Crash)  
**Status:** Resolved  
**Modules:** `managers/Display/parser/layout_parser.py`, `workers/Command_Router/MIDI/midi.py`, `workers/Command_Router/OSC/osc.py`, `workers/Command_Router/SNMP/snmp.py`

## Issue 1: UI Startup Crash (KeyError: 'orientation')
The application failed to launch Partition B (UI) with a `KeyError: 'orientation'` in `managers/Display/builder/gui_display.py`.

### Root Cause
The `LayoutParser._parse_directory_listing` method (used when no `layout.json` is present) correctly identified split layouts based on directory names (e.g., `left_50`, `top_100`) but failed to inject the `orientation` key into the returned data dictionary. The UI builder expected this key to instantiate the `ttk.PanedWindow`.

### Resolution
Updated `LayoutParser._parse_directory_listing` to include the `orientation` key (using `tk.HORIZONTAL` or `tk.VERTICAL`) in the `parsed_data` object.

## Issue 2: MIDI/OSC/SNMP Dispatch Error
The CORE partition reported multiple `AttributeError` exceptions when attempting to dispatch messages via the new modularized `ProtocolRouter`.
Error: `'MidiManager' object has no attribute 'publish'`

### Root Cause
The modularization of `ProtocolRouter` shifted the system from a passive observer-based dispatch pattern to an explicit dispatch pattern. The new `dispatch.py` module expected transport managers to implement `publish` or `send` methods, which were missing from the legacy transport classes.

### Resolution
Implemented the required interface methods in all transport managers:
- **MIDI**: Added `publish(topic, val, meta)` and moved outbound sync logic from the observer callback.
- **OSC**: Added `send(address, value, meta)` and refactored outbound logic.
- **SNMP**: Added a stub `publish` method to satisfy the router's API contract.

## Verification Evidence
1. **UI Fix**: Verified via `reproduce_ui_crash.py` that `parse_directory` now correctly includes the `orientation` key for split layouts.
2. **Dispatch Fix**: Source code audit confirms that `dispatch.py` calls now map to valid methods in all transport managers.

## Impact
Restores UI stability and enables bidirectional communication across all protocol bridges.
