# Bug Report: BUG_20260329_225000

## Issue
The MIDI manager was emitting repetitive "heartbeat" debug logs every 30 seconds for each active MIDI port, even when `LOCAL_DEBUG` was disabled.
Example: `💓 [MIDI-LISTEN] Loop active for Arturia MicroLab`

## Root Cause
The heartbeat log statement in `oaComMidi/Managers/midi_manager.py` was not wrapped in an `if LOCAL_DEBUG:` gate.

## Resolution
Wrapped the `midi_logger.debug()` call within the `_midi_listen_loop` method with an `if LOCAL_DEBUG:` check.

## Verification
1.  Verified that `LOCAL_DEBUG` is set to `False` by default in the file.
2.  Performed a syntax check on the modified file.
