# Bug Report: BUG_20260330_004500

## Issue
The "Maintenance (CLEAR)" operations in the `oaTests` right panel were taking up significant vertical space, leading to a cluttered user interface.

## Root Cause
Legacy design placed all individual cleanup buttons (Logs, Audits, MQTT, etc.) directly in the primary side panel.

## Resolution
1.  **Maintenance Pop-up**: Created `oaTests/Interface/maintenance_clear_screen.py`, a dedicated Textual `Screen` that centralizes all system cleanup operations in a modal-style dialog.
2.  **UI Consolidation**: Updated `oaTests/Interface/right_panel.py` to remove the individual cleanup buttons and replace them with a single, high-contrast "CLEAR MENU" button.
3.  **Action Delegation**: Implemented logic in the new screen to delegate cleanup commands back to the main `TestsApp` orchestrator, ensuring thread safety and consistent logging.

## Verification
1.  Manual UI audit confirms the "CLEAR MENU" button is correctly positioned in the right panel.
2.  Clicking the button launches the "MAINTENANCE: CLEAR OPERATIONS" pop-up.
3.  Verified that all cleanup buttons (e.g., CLEAR LOGS, DELETE CACHE) within the pop-up still trigger their respective worker threads and log results to the center panel.
4.  The "CLOSE & RETURN" button correctly dismisses the pop-up.
