# Bug Report - 2026-04-02 23:30:00

## Issues Resolved

### 1. CRITICAL: `MqttMessage` NameError
- **Root Cause**: Circular/Premature type hinting reference in `oaStateCache/Core/state_cache.py`.
- **Resolution**: Converted type hints to strings ('MqttMessage') to allow forward referencing.

### 2. CRITICAL: Rust Compilation Failures
- **Root Cause**: `pyproject.toml` files required a `README.md` that did not exist.
- **Resolution**: Created empty `README.md` files in all new native module roots.

### 3. HIGH: REST Dashboard NameError
- **Root Cause**: Conditional import of `REST_MODULE` failed when paths were already set.
- **Resolution**: Updated `gui_REST.py` to ensure the module is always imported.

### 4. HIGH: SMPTE 2138 API Mismatch
- **Root Cause**: GUI monitor was calling a non-existent callback registration API on the manager.
- **Resolution**: Migrated monitor to use the system `event_bus` for traffic updates.
