# Bug Log: BUG_20260403_012500

## Issue: Multiple System Component Failures and Boot Crashes
Several critical issues were identified through test failures and log analysis:
1. `oaComBroker`: Missing `rust_router` attribute in `ProtocolRouter` and incomplete ingestion into the Rust core.
2. `oaComProtocols.oaComVisa`: SCPI devices (Port 5025) were skipped during network discovery if VXI-11 (Port 111) checks failed.
3. System Stability: Code -11 (Segmentation Fault) crashes during boot state restoration.
4. Test Regressions: `test_logic_mqtt_publisher` and `test_agent_mdns_zeroconf` were failing due to outdated logic and improper mocking.

## Root Cause Analysis
1. **Missing Attribute**: The `ProtocolRouter` was refactored but the `rust_router` initialization was accidentally omitted from `__init__`.
2. **Logic Bug**: `_check_host` used a structure that returned `None` prematurely upon Port 111 failure, bypassing Port 5025.
3. **Resource Exhaustion**: High-volume message ingestion during boot state restoration overwhelmed the Rust router dispatch threads and the UI thread, causing memory corruption/crashes.
4. **Mocking Protocol**: `test_agent_mdns_zeroconf` didn't correctly implement the context manager protocol (`__enter__`/`__exit__`) for mocked sockets.

## Resolution
1. **oaComBroker**: Restored `self.rust_router` to `ProtocolRouter.__init__`. Updated `normalize_and_ingest` and `create_silent_msg` to push messages to the Rust core.
2. **oaComProtocols.oaComVisa**: Restructured `_check_host` to ensure Port 5025 is probed regardless of Port 111 results.
3. **Stability**: Implemented a 1ms throttle in `state_cache.py` and a 2ms throttle in `gui_state_restorer.py` during boot restoration.
4. **Testing**: Updated `test_logic_mqtt_publisher` to match bulk-publishing logic and fixed `test_agent_mdns_zeroconf` socket mocks.

## Verification Evidence
- Ran `pytest` on `oaComBroker` and `oaComProtocols.oaComVisa` test suites.
- **Results**: 12/12 Tests Passed.
- Log verified: [INBOUND] and [OUTBOUND] traces show correct throttling and ingestion flow.
