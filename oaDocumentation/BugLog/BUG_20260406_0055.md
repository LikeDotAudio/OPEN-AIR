# Bug Report: BUG_20260406_0055

## Issue
Timestamps still visible in logs despite configuration.

## Root Cause
The log format strings in `oaLogging/Core/logger.py` were hardcoded to include the timestamp regardless of the configuration.

## Resolution
- Updated log format strings to dynamically include/exclude timestamp based on the `timestamp_logs` setting.

## Verification
- Analyzed generated log outputs to confirm timestamp absence.
