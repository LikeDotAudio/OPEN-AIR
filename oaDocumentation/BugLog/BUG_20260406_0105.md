# Bug Report: BUG_20260406_0105

## Issue
Graphs are completely invisible or not displaying datasets for components lacking explicit grid sticky/stretch attributes (e.g., Scan.json).

## Root Cause
1. `dynamic_graph.py` explicitly overwrote its requested frame dimensions to 1x1 during initialization (an old X11 BadValue workaround), which alongside `pack_propagate(False)` meant the widget rendered at 1x1 pixels unless stretched by a parent container.
2. JSON multi-lingual dictionary objects were passed raw to Matplotlib axis and line label functions, causing potential rendering errors or ugly `str(dict)` outputs.

## Resolution
- Removed the `self.config(width=1, height=1)` override. The frame now respects the `width` and `height` constraints parsed directly from the layout JSON schema (minimum 100x50).
- Wrapped all dictionary-based labels with `get_text()` in `dynamic_graph.py` and `graph_styler.py`.

## Verification
- The graphing widgets will now reserve their correct physical size and draw Matplotlib figures synchronously without relying on parent layout stretch events.
