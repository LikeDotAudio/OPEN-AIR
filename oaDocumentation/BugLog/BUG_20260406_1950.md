# Bug Log: 20260406_1950

**Issue**: Unhandled KeyboardInterrupt in the UI partition led to messy tracebacks when shutting down with CTRL+C.

**Root Cause**: Tkinter's root.mainloop() does not catch KeyboardInterrupt, and the main() function in loader_main_service.py was not wrapping the loop in a try-except block.

**Resolution**:
- Refactored `LoaderShutdownService` to include a synchronous `shutdown()` method for use when the GUI event loop is interrupted.
- Wrapped the `main()` function logic in `oaGui/Managers/loader_main_service.py` in a `try...except KeyboardInterrupt` block.
- Added safety checks for `root` destruction to handle early interruptions.

**Verification**: Code reviewed and structured for robust handling of both early and late interrupts.
