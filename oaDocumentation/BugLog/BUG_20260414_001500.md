# 🏷️ BUG REPORT: [NMOS] Entry Point API Regression (ImportError)

**ID**: BUG_20260414_001500
**Priority**: 1
**Status**: RESOLVED

## 📖 Description
Refactoring of `oaComNmos/Entry.py` led to the renaming of `stop()` to `shutdown_nmos()` and the omission of `status()`. This caused `ImportError` in the unit test suite and external modules relying on the standard protocol manager API.

## 🛠️ Root Cause
API mismatch between implementation and expected interface in `test_nmos_manager.py`.

## 🚀 Fix Action
1. Renamed `shutdown_nmos()` back to `stop()`.
2. Restored `status()` function to report registration and running state.
3. Updated `__all__` and `main()` cleanup logic to use the restored function names.

## ✅ Verification
Verified with `unittest` (All tests passed) and standalone GUI execution.
