# Bug Log - 20260415_222400

**Module**: `oaStateCache`, `oaGuiManager`
**Priority**: 1 (Critical)
**Status**: Resolved

## Description
A large number of "Deferred build error" messages were identified in the UI bootstrap sequence. Investigation revealed two primary root causes:
1. `AttributeError: 'NoneType' object has no attribute 'trace_add'` in `StateMirrorEngine.register_widget`.
2. `ModuleNotFoundError: No module named 'oaGuiElements.Core.graphing.plot_widget_adapter'` during widget creation.

## Root Cause Analysis
1. **AttributeError**: Some complex widgets (like `JsonTree`) do not use a standard `tk.Variable` for state management and pass `None` to the registration system. The engine was assuming a variable was always present.
2. **ModuleNotFoundError**: The `plot_widget_adapter.py` file was moved to a `Methods/` subdirectory, but the factory mapping in `oaGuiManager` was still using the old path.

## Fix Applied
1. **StateMirrorEngine**: Added a conditional check `if tk_variable:` before calling `.trace_add()`.
2. **Factory Mapping**: Updated `oaGuiManager/Core/factory/Core/factory_mapping.py` to use the correct absolute path: `oaGuiElements.Core.graphing.Methods.plot_widget_adapter`.

## Verification Results
- **Reproduction Script (StateMirror)**: Confirmed that `register_widget` now handles `None` variables gracefully.
- **Import Test (Adapter)**: Confirmed that the `plot_widget` creator can now be successfully loaded via the factory mapping.
