# Bug Fix: AttributeError in TreeRefactor Initialization
# Date: 2026-04-16 22:40:00
# Status: RESOLVED

## Description
A crash occurred during WYSIWYG Editor startup: `AttributeError: 'TreeRefactor' object has no attribute '_last_clean_path'`. This was caused by a race condition where the `__init__` method called `_on_state_updated`, which in turn accessed `_last_clean_path` before it was formally initialized in the constructor.

## Trigger
Launching the WYSIWYG editor with pre-existing state data.

## Action Taken
1.  Modified `oaGuiEditorWYSIWYG/Interface/workspaces/tree_refactor.py`:
    - Reordered the `__init__` sequence to define `_dragging_item` and `_last_clean_path` immediately after the superclass initialization.
    - Moved UI building and event subscriptions below state variable definitions.

## Verification
- Ran existing unit tests `Tests/test_core_components.py` -> PASSED (12/12 tests).
- Verified that the initialization sequence now standardizes attribute availability before any downstream logic execution.
