# Bug Fix: Missing Method and Broken Imports in WYSIWYG
# Date: 2026-04-16 22:55:00
# Status: RESOLVED

## Description
Two issues were identified during testing:
1. `AttributeError: 'WysiwygEditor' object has no attribute '_save_and_close'` - The menu was attempting to bind to a method that was missing from the refactored `WysiwygEditor` class.
2. `ModuleNotFoundError` in `test_core_components.py` - The test was attempting to import from `Interface.layout_engine.overlay` which had been renamed to `Interface.layout_engine.overlay_manager`.

## Trigger
- Startup of the WYSIWYG editor.
- Running the automated test suite.

## Action Taken
1.  **Implemented `_save_and_close`**: Added the missing method to `oaGuiEditorWYSIWYG/Managers/wysiwyg_editor.py` to allow the "Save & Close" menu option to function.
2.  **Fixed Test Imports**: Updated `oaGuiEditorWYSIWYG/Tests/test_core_components.py` to correctly reference `overlay_manager` instead of `overlay`.
3.  **Corrected Patch Targets**: Updated `unittest.mock.patch` calls in the test suite to point to the new module location.

## Verification
- Ran `oaGuiEditorWYSIWYG/Tests/test_Entry.py` -> PASSED.
- Ran `oaGuiEditorWYSIWYG/Tests/test_core_components.py` -> PASSED (12/12 tests).
