# Bug Log: 20260416_234500

## Description
Accidental deletion of core `DynamicGuiBuilder` methods during horizontal scroll implementation. This caused initialization failures in the preview engine and crashes during scrolling.

## Error Clusters
- **Cluster A: Initialization Failure**: `DynamicGuiBuilder` missing `_setup_event_bindings`.
- **Cluster B: Scrolling Logic Failure**: `DynamicGuiBuilder` missing `_trigger_scroll_sync` (and `_perform_scroll_sync`).

## Trigger Event
Triggered by the implementation of horizontal scrolling where an overly broad `replace` call removed several adjacent methods.

## Domain Mapping
- `oaGuiBuilder/Workers/builder.py`

## Action Taken
Restored the following missing methods:
- `start()`
- `_setup_event_bindings()`
- `_trigger_scroll_sync()`
- `_perform_scroll_sync()`
- `_on_canvas_configure()`

## Verification Results
Methods have been re-inserted into the source file. The attributes are now available on the `DynamicGuiBuilder` instance, resolving the `AttributeError`.
