# BUG_20260502_091500: Comprehensive oaGui Naming Convention Refactor

## 🔍 Phase 1: Research, Clustering & Identification

### Error Clusters
1. **[BUILDER] Magic Numbers**: Hardcoded pixel values and limits in `yak_log_pane.py`, `base_widget_creator.py`, and `command_router.py`.
2. **[MANAGER] Short Variable Names**: Overly abbreviated variables (`r`, `c`, `m`, `v`, `w`, `h`) in core layout and monitoring logic.
3. **[SYSTEMIC] Noise Words**: Redundant `data` suffix in `config_data`, `src_data`, `dest_data` across 50+ files.
4. **[METHODS] Generic Function Names**: Ambiguous method names like `defer`, `track`, and `merge`.
