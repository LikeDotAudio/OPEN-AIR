BUG LOG: 20260403_002830

Date: 2026-04-03

Issue: Critical GUI Crashes and Spamming Errors

Root Cause: API mismatches, incorrect logging calls, and missing return values in Python-Rust bridge.

Analysis

  • SmartMeter Error: BallisticsEngine.update was not returning the tuple from the underlying Rust engine, causing a TypeError when unpacking in SmartMeter._animate.
  • TextValueWithUnits TypeError: matrix_log calls in text_value_with_units.py passed unsupported keyword arguments (file, version, function).
  • TextValueWithUnits KeyError: logger.exception string was not an f-string, causing a ‘KeyError: 'label’during error reporting.
  • **CMDP Attribute Error**:circular_motion_displacement_potentiometer.pycalledf.render()onCMDP_LTPObjectinstances, which only implementrender_fader_visuals()`.

Resolution

  1. Updated oaGuiElements/Core/metering/meter_bar/Core/ballistics.py: Added return to update method.
  2. Updated oaGuiElements/Core/text/text_value_with_units/text_value_with_units.py:
    • Removed file, version, and function from matrix_log calls.
    • Corrected os.path.basename error.
    • Converted logger.exception message to an f-string.
  3. Updated oaGuiElements/Core/utils/circular_motion_displacement_potentiometer/circular_motion_displacement_potentiometer.py: Renamed f.render() to f.render_fader_visuals().
  4. Updated oaGuiElements/Core/special/circular_motion_displacement_potentiometer/circular_motion_displacement_potentiometer.py: Renamed f.render() to f.render_fader_visuals().

Verification Evidence

  • BallisticsEngine import and structure verified.
  • text_value_with_units.py syntax verified with py_compile.
  • Manual inspection of CMDP_LTPObject confirmed render_fader_visuals() is the correct method.
