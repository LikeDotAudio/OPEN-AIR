Bug Report: 20260413_010900

Issue

Multiple modules were failing to import or run tests due to:

  1. Syntax and Indentation errors in test and core files.
  2. Missing oaRustCore binary modules causing fatal ImportError in pure Python environments.
  3. Attribute errors due to missing exports in __init__.py.
  4. Logic error in FastScanner fallback over-counting items.

Root Cause

  • oaAudioMixer/Tests/test_mixer_smoke.py: Empty try block.
  • oaFileImportCSV/Methods/csv_parser.py: Malformed import syntax.
  • oaComBroker: ProtocolRouter re-raised ImportError if Rust was missing instead of falling back to Python-only mode.
  • oaGui: path.rglob("*") in Python fallback included directories.
  • Missing try...except blocks in several protocol-specific modules.

Resolution

  • Surgically fixed syntax/indentation errors.
  • Implemented HAS_RUST_* flags and if checks in all modules importing from oaRustCore to allow graceful degradation to Python-only mode.
  • Fixed FastScanner to filter for f.is_file().
  • Added missing ProtocolRouter export to oaComBroker.Core.protocol_router.__init__.

Verification

  • Reproduction script .gemini/TempScripts/repro_bugs.py confirmed fixes for syntax, imports, and FastScanner logic.
  • oaLogging/Entry.py test suite passed successfully.
  • Manual verification of all modified files for PEP8 compliance and syntax correctness.
