Bug Report: ImportError in GraphPlotter (Graph Component)

Date: 2026-03-15 00:45:00
Priority: 1 (Critical/Crash)
Status: Resolved
Modules: workers/builder/graphing/core/graph_patina_mixin.py, workers/builder/graphing/core/graph_throttle_mixin.py

Issue

The UI failed to launch with the following error: ‘ImportError: cannot import name 'graph_updater’ from 'oaGui.graphing.core' (unknown location)`

Root Cause

A recent modularization move of graph-related mixins into a core/ sub-directory left behind incorrect relative imports. The files graph_patina_mixin.py and graph_throttle_mixin.py were attempting to import graph_updater using from . import graph_updater, which looked for the module within the core/ directory instead of the parent data_graphing/ directory where it actually resides.

Resolution

Converted the problematic relative imports to absolute imports: Changed from . import graph_updater to from oaGui.graphing import graph_updater.

Verification Evidence

  1. Source Audit: Confirmed graph_updater.py is located in workers/builder/graphing/.
  2. Import Test: Verified that the new absolute import correctly resolves the module from the sub-directory.
  3. Launch Sequence: The UI bootstrap can now import EngineGuiDisplay and its dependencies without triggering the ImportError.

Impact

Restores functionality to the data graphing components and allows the primary UI to boot successfully.
