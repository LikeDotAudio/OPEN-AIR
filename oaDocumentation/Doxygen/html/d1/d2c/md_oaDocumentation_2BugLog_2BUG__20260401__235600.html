Issue: IndentationError in Setup.py causes SystemExit on startup.

🔍 ISSUE DESCRIPTION

The testing suite failed to launch with a SystemExit: 1 due to an IndentationError in oaInstallation/Managers/Setup.py. The error originated from the _inject_project_root function where a return statement was not properly indented.

🛠️ ROOT CAUSE

Malformed code in oaInstallation/Managers/Setup.py:

def _inject_project_root():
if project_root not in sys.path:
return project_root

vector

The return statement was on the same indentation level as the if statement.

🚀 RESOLUTION

Surgically corrected the indentation in oaInstallation/Managers/Setup.py and ensured the function always returns the project_root variable.
