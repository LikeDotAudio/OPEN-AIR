Bug Report: NameError in StateCacheManager

Date: 2026-03-16 00:50:00 Priority: 1 (Critical/Crash) Impact: Bootstrap failure during State Cache initialization, preventing the application from starting.

Issue

A ‘NameError: name 'data_logger’ is not definedoccurred inworkers/Command_Router/State_Cache/state_cache.py` on line 49.

Root Cause

The StateCacheManager was using data_logger for various logging tasks, but it was not imported from oaLogging.logger.

Resolution

Modified workers/Command_Router/State_Cache/state_cache.py to import data_logger from oaLogging.logger. Removed the unused builder_logger from the same import line to keep the code clean.
