Bug Report: BUG_20260330_003000

Issue

The Debug Matrix checkboxes were occupying too much space in the main oaTests side panel, causing UI clutter.

Root Cause

Initial implementation of the new Hierarchical Debug Matrix placed all toggles directly in the LeftPanel.

Resolution

  1. Pop-up Screen: Created oaTests/Interface/debug_matrix_screen.py, a dedicated Textual Screen that houses the hierarchical checkboxes in a centralized dialog box.
  2. UI Cleanup: Updated oaTests/Interface/left_panel.py to remove the bulk checkboxes and replace them with a single "CONFIGURE DEBUG" button.
  3. Navigation Logic: Updated oaTests/Interface/TestsUI.py to push the new DebugMatrixScreen when the configuration button is clicked and remove legacy event handlers from the main app scope.

Verification

  1. Manual UI audit confirms the "CONFIGURE DEBUG" button is visible and properly themed.
  2. Clicking the button launches the "DEBUG MATRIX CONFIGURATION" pop-up.
  3. Toggling checkboxes within the pop-up correctly updates config.ini on disk.
  4. The "CLOSE & RETURN" button correctly returns the user to the main test suite.
