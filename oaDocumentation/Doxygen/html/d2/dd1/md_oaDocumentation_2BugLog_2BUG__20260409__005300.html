BugLog Entry: 20260409_005300

Issue Summary

Tests for oaGui.Tests.test_shutdown_coordinator were triggering an Exception ignored message in environments running with a debugger (like pydevd). The error was: TypeError: isinstance() arg 2 must be a type, a tuple of types, or a union.

Root Cause Analysis

The unit tests were patching threading.Thread with a MagicMock. When the ShutdownCoordinator.on_closing() method attempted to start a thread via this mock, the debugger's monkey-patching logic (e.g., _pydevd_sys_monitoring_cython._create_thread_info) intercepted the call. Because the second argument to an isinstance check inside the debugger was likely expecting a real type but received a Mock (or had become None during test teardown), it crashed.

Resolution

  1. Refactored Production Code: Updated ShutdownCoordinator.on_closing() to accept an optional run_async parameter (default True). This allows the caller to explicitly request synchronous execution of the shutdown sequence.
  2. Optimized Test Suite: Refactored oaGui/Tests/test_shutdown_coordinator.py to use run_async=False. This executes the shutdown logic directly in the test thread, completely bypassing the need to mock or start background threads.

Verification Evidence

  • Local Verification: Ran python -m unittest oaGui/Tests/test_shutdown_coordinator.py.
  • Results: All 3 tests passed successfully.
  • Improved Stability: Bypassing background threads in unit tests eliminates race conditions and interaction bugs with external monitoring tools (debuggers, profilers).
