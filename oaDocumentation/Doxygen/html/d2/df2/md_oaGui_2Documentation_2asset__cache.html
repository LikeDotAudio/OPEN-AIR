🏷️ Asset Cache Manager

📖 Description & Purpose

File Level

core/asset_cache_manager.py

Utility to cache procedurally generated assets (panels, screws, etc) to disk and memory. Prevents expensive PIL re-generation and redundant disk I/O.

Author: Anthony Peter Kuzub Version 20260218.Optimization.1
