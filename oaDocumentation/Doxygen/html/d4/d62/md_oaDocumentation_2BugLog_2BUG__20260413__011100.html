Bug Report: 20260413_011100 - Architectural Audit Refactors

Issue

An architectural audit identified several violations of clean code principles:

  1. Law of Demeter ("Train Wrecks"): Long chains of method calls in oaGui and oaGuiEditorWYSIWYG.
  2. Excessive Multiple Inheritance: Heavy use of mixins in oaComVisa causing high coupling.

Root Cause

  • oaGui/Methods/active_marker_tune_and_collect.py: Nested try...except and long string manipulation chains for MQTT payload parsing.
  • oaGuiEditorWYSIWYG/Core/workspaces/layout_overlays/sizing.py: Redundant winfo_toplevel().winfo_rootx() calls on every mouse event.
  • oaComProtocols/oaComVisa/Core/visa_fleet.py: FleetOrchestrator inherited from three separate mixins, making state management opaque.

Resolution

  • Refactored MarkerGoGetterWorker: Extracted a unified _is_payload_true method to handle JSON and raw-string MQTT payloads safely.
  • Optimized Sizing Tooltips: Cached winfo_toplevel() reference and reduced redundant calculations during drag operations.
  • Decomposed FleetOrchestrator: Converted FleetCommandQueueMixin, FleetInventoryMixin, and FleetScanMixin into composed CommandQueueManager, InventoryManager, and ScanManager classes.

Verification

  • Verified _is_payload_true logic with comprehensive test cases in .gemini/TempScripts/test_payload_parsing.py.
  • Manual verification of FleetOrchestrator public API compatibility through property and method delegation.
