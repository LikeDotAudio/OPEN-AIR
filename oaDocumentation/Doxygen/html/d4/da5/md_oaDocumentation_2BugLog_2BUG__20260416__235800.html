Error Clusters

  • Cluster A: Composite Widget Assembly Failure: Multiple instances of AttributeError when accessing .variable on a tuple instead of a widget instance.

Trigger Event

GUI rebuild or interactive layout refresh containing OcaCompositeFaderKnob elements.

Domain Mapping

  • oaGuiElements/Core/utils/composite_horizontal_dial_value/composite_horizontal_dial_value.py

Action Taken

  • Modified _assemble_ui in composite_horizontal_dial_value.py to correctly unpack the returned tuples:
    • fader_widget, _ = self.make_fader_horizontal(...)
    • dial_widget, _ = self.make_knob(...)

Verification Results

Source code corrected to handle standard factory return types. This ensures the .variable attribute (present on the frame/hull) is correctly accessed for trace bindings.
