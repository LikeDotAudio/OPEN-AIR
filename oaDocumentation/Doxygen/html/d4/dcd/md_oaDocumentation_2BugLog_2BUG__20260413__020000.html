  1. Cluster 1: [REST] Uvicorn failed to start on 0.0.0.0:44868. Error: 1

    • Trigger: Starting Uvicorn (likely port collision).
  2. Cluster 2: Tkinter Exception: IndexError: tuple index out of range
    • Target: oaGui.Interface.viewport.tab_physical_window & oaGuiElements.Core.Knobs.knob.Core.knob_renderer
    • Trigger: Drawing knob visuals (create_polygon).

Root Causes:

  • REST Port Collision: Uvicorn's server exits with SystemExit(1) if the port is busy, bypassing the standard OSError catch and resulting in an ambiguous Error: 1 string.
  • Tkinter Missing Geometry: If the oaRustCore module fails to load (e.g., FFI broken or uncompiled), the fallback RotaryCore was returning []. This caused the geometry to be missing completely, producing an IndexError when Tkinter _flatten resolved the coordinates list to ().

2. Plan of Action

  1. Fix Rest Uvicorn Worker: Update uvicorn_worker.py to capture SystemExit(1) directly to log a logger.warning for Port Collisions instead of treating it as a generic crash.
  2. Fix Rotary Core: Edit oaGuiElements/Methods/rotary_core.py to provide a Python math fallback (generating correct math.sin and math.cos points) for get_poly_points and get_gear_points when the high-performance Rust core is uncompiled or unavailable.
