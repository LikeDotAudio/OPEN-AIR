Bug Report: [ROUTER] ImportError: 'router_logger' Missing in logger.py

📅 Timeline

  • Discovery Date: 2026-03-14 01:46:27
  • Resolution Date: 2026-03-14 14:15:00
  • Priority: 1 (Critical/Crash)

🔍 Issue Summary

The OPEN-AIR application failed to bootstrap both the UI and Core partitions due to a missing standardized logger (router_logger) in workers/logger/logger.py. This caused a cascading ImportError in ProtocolRouter, which is a central dependency for almost all communication subsystems.

🪱 Root Cause

A recent refactoring or update (likely 20260313.Router.Refactored) added a dependency on router_logger in workers/Command_Router/protocol_router.py, but this logger was never defined in the central workers/logger/logger.py registry.

🛠️ Resolution

  1. Modified workers/logger/logger.py: Added router_logger = logger.bind(category="ROUTER") to the standardized subsystem loggers.
  2. Cleaned workers/Command_Router/protocol_router.py:
    • Removed redundant loguru and duplicate router_logger imports.
    • Restored the missing LOCAL_DEBUG flag required for trace logging.
    • Restored descriptive comments for the debug setup.

✅ Verification Evidence

  • Empirical Proof: Verified successful import of ProtocolRouter, OSCManager, and StateCacheManager via CLI.
  • Command: ‘python3 -c "from oaComBroker.Managers.protocol_router import ProtocolRouter; from oaComProtocols.oaComOSC.Managers.osc_manager import OSCManager; from workers.Command_Router.State_Cache.state_cache import StateCacheManager; print('Success&rsquo;)"
  • **Result**:Success`

📋 System Impact

  • Core Bootstrap: Restored.
  • MQTT/OSC Message Routing: Restored.
