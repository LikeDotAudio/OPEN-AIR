74# Temporarily disables emitting of event notifications (to all subscribers, not
75# just to the subscriber calling this method). Events from the Subscription
76# Manager itself are not disabled. This method can be used if either a
77# controller or the local device knows that it is going to change the state of
78# the device significantly, which could lead to a notification storm of events.
79# Invoking this method will prevent the notification storm. The event '03e01
80# EventsDisabled' will be raised to notify all controllers of the fact that
81# events are temporarily disabled. The subscription manager will start
82# collecting the object numbers of the objects that raise events, so that it can
83# pass a list of changed objects once the events are re-enabled. The return
84# value indicates if disabling events succeeded.
85#
86# @method OcaSubscriptionManager#DisableNotifications
87# @returns {Promise<None>}
88# Re-enables the sending of event notifications to all subscribers. When events
89# are re-enabled, the subscription manager will raise the **SynchronizeState**
90# event, passing the list of objects that have changed state. Subsequently, the
91# subscription manager will transmit all notifications as normal. If the
92# connection to the controller that invoked the DisableEvents() is lost, this
93# method will be called automatically to prevent the situation in which the
94# raising of events would never be re-enabled. The return value indicates if
95# re-enabling the event-based events succeeded.
