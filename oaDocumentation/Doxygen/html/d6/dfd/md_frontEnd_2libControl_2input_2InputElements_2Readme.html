InputElements — basic input bundle

A small bundle of plain form controls used by the input demo.

  • Defines (globals): OcaCheckbox, OcaDropdown, OcaIncDecButtons
  • Loaded by: the live app via frontEnd/Core/Launch/index.html.
  • Demo: open ../index.html.

‍Note: OcaCheckbox here is the simple form variant. The MQTT-aware OcaCheckbox lives in ../OcaCheckbox/ and is loaded after this file in Core/Launch/index.html, so it wins (same global name). Keep that load order in mind if you edit either.
