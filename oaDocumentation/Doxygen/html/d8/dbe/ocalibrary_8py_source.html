11# A **library** is an agent that holds a collection of datasets. We refer to
12# each dataset as a **Volume**. There are two kinds of volumes: **ParamSet**
13# (parameter set). A ParamSet is a collection of operating parameter settings
14# that can be applied to a block. Each ParamSet is associated with a specific
15# block type, but not with a specific instance of that type. A ParamSet may be
16# applied to any block instance of the associated type. A block's type is the
17# object number of its factory or, for factory-defined blocks, a unique
18# identifier set at time of manufacture. **Patch**. A Patch is a collection of
19# ParamSet assignments. A ParamSet assigment is the description of a binding of
20# a ParamSet to a block instance. To "apply" a Patch is to apply all of its
21# assignments. To apply an assignment is to set all of its ParamSet's parameter
22# values into its block. A given library instance can only hold one class of
23# volume. A device that supports libraries can have any number of Patch and
24# ParamSet libraries. If a device implements a Patch library, it must also
25# implement at least one ParamSet library. However, the reverse is not true: a
26# device may implement one or more ParamSet libraries without a Patch library.
