Bug Log: BUG_20260404_221000

Issue: MIDI Tests Skipped and IndentationError in FileIOHandler

Date: 2026-04-04 Severity: High (Blocking test execution and build failure) System: TEST / GUI Module: oaTests.Core, oaGuiEditorWYSIWYG.Core.file_io_handler

Symptom

  1. MIDI tests in oaComProtocols.oaComMidi/Tests/ were being skipped with the message: Skipping real MIDI test in safety mode.
  2. A regression in oaGuiEditorWYSIWYG/Core/file_io_handler.py caused an IndentationError during test discovery: IndentationError: unindent does not match any outer indentation level (line 157).

Root Cause

  1. MIDI Skip: The OPEN_AIR_SKIP_REAL_MIDI environment variable was hardcoded to "1" in oaTests/Core/Entry.py, preventing users from enabling these tests even if they had the required hardware/drivers.
  2. IndentationError: A previous fix for the matrix_log signature introduced misaligned blocks in FileIOHandler.save_file.

Resolution

  1. MIDI Skip Fix: Modified oaTests/Core/Entry.py to only set OPEN_AIR_SKIP_REAL_MIDI = "1" if it is not already defined in the environment. python if os.environ.get("OPEN_AIR_SKIP_REAL_MIDI") is None: os.environ["OPEN_AIR_SKIP_REAL_MIDI"] = "1"
  2. Indentation Fix: Surgically corrected the indentation of the matrix_log calls and the on_save_callback() call in oaGuiEditorWYSIWYG/Core/file_io_handler.py.

Verification

  • Reproduction: Ran export OPEN_AIR_SKIP_REAL_MIDI=0 && python3 oaTests/Core/Entry.py.
  • Result:
    • ⏭️ Skipped: 0 (Confirmed MIDI tests are now executing).
    • Passed: 310 (All tests, including MIDI and FileIO tests, are passing).
  • System Stability: Confirmed that the IndentationError is resolved and oaGui.Tests.test_ui_and_data now imports correctly.

🚀 Addition: Improved Test Controllability

The test runner now respects external environment variables, allowing for more flexible CI/CD and local development configurations.
