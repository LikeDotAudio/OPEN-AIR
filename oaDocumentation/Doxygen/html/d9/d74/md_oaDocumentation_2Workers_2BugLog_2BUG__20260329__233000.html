Bug Report: BUG_20260329_233000

Issue

High-velocity debug logs and repetitive initialization messages were flooding the console even when the system was running in non-debug mode. This made it difficult to monitor critical system events.

Root Cause

Multiple modules across the codebase contained logger.debug(), logger.info(), or print() statements that were not wrapped in if LOCAL_DEBUG: gates, violating the project's Zero-Cost Gates architectural mandate.

Resolution

Applied comprehensive gating to the following modules:

  1. oaGui: Gated window creation and service composition logs in ui_window.py and composition_root.py.
  2. oaGuiElements: Gated lifecycle and status update logs in splash_screen.py.
  3. oaGui/Core/factory: Gated widget discovery and registry merge logs in widget_discovery_engine.py.
  4. oaComProtocols.oaComSNMP: Gated thread startup/shutdown and network linking logs in snmp_manager.py, snmp_state_persister.py, and snmp_log_monitor.py.
  5. oaComProtocols.oaComMidi: Gated repetitive heartbeat logs in midi_manager.py.

Verification

  1. Verified that LOCAL_DEBUG is set to False by default in all modified files.
  2. Log analysis of subsequent runs confirms a significantly quieter console, with only SUCCESS, WARNING, and ERROR messages appearing by default.
