1"""
2openair.py — Multi-process supervisor entry point for OPEN-AIR.
3
4The supervisor's job is small and well-defined:
5 1. (optional) Direct-launch a single partition if asked (--core/--ui/--web).
6 2. (setup) Verify environment, validate scripts, build per-partition envs.
7 3. (boot) Initialise the Communication Protocol Manager (registration only).
8 4. (spawn) Launch UI → Core → Web as subprocesses.
9 5. (monitor) Watch their liveness and (in mission-critical mode) restart on crash.
10 6. (shutdown) Terminate children, stop protocols, flush logs, exit.
11
12All real work lives in `oaSupervisor/` — this file is just orchestration.
13
14Author: Anthony Peter Kuzub
15"""
