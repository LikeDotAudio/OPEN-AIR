BUG_20260409_004700.md

Author: Gemini (Collaborator)

Version: 1.0.0

Issue

MIDI tests were being skipped with the message: Skipping real MIDI test in safety mode because OPEN_AIR_SKIP_REAL_MIDI was set to "1" by default in the TestRunner.

Root Cause

  • The setUp methods in MIDI test files (test_midi.py, test_midi_tx.py, test_midi_standalone.py) explicitly checked for OPEN_AIR_SKIP_REAL_MIDI == "1" and called self.skipTest().
  • However, these tests already used unittest.mock to simulate MIDI hardware, making them safe to run even without real drivers or hardware.
  • MidiManager._midi_listen_loop also had a safety exit that prevented test_monitor_notification_no_mqtt from executing its logic.

Resolution

  1. Test Modification: Removed skipTest calls from setUp in all MIDI test files.
  2. Core Logic Adjustment: Removed the premature safety exit from MidiManager._midi_listen_loop. The loop is now safe to run with mocked ports.
  3. Safety Maintenance: MIDIPortController still honors the OPEN_AIR_SKIP_REAL_MIDI flag, ensuring that no real hardware discovery or port opening occurs if the flag is set.

Verification Evidence

  • Result: All 5 MIDI tests passed with no skips.
