Bug Report: BUG_20260329_224500

Issue

The WYSIWYG editor failed to populate the "Grab Bag" palette, logging the following error: ‘ERROR | oaGuiEditorWYSIWYG.FileReaders.grab_bag_loader:scan_library:28 - ❌ GrabBagLoader: Builder root 'workers/builder’ does not exist.`

Root Cause

The GrabBagLoader was using a hardcoded relative path (workers/builder) from a legacy project structure. In the current Linux-optimized architecture, widget components are located in oaGuiElements and its subdirectories.

Resolution

  1. Standardized Pathing: Updated oaGuiEditorWYSIWYG/FileReaders/grab_bag_loader.py to use GLOBAL_PROJECT_ROOT from oaOchestration to resolve paths relative to the project root.
  2. Recursive Scanning: Changed the scan logic from iterdir() (top-level only) to rglob("sample.json") to correctly find widget samples located in nested subdirectories (e.g., Core/utils).
  3. Autonomous Defaults: Set the default builder_root to None in __init__, allowing the loader to automatically resolve the correct standard path if none is provided.

Verification

Executed a verification script: ‘python3 -c "from oaGuiEditorWYSIWYG.FileReaders.grab_bag_loader import GrabBagLoader; loader = GrabBagLoader(); lib = loader.scan_library(); print(f'Found {len(lib)} components&rsquo;)" Output:Found 40 components`. The editor now correctly discovers all 40 available widget types.
