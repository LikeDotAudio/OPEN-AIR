🏷️ Active Marker Tune And Collect

📖 Description & Purpose

File Level

active/active_marker_tune_and_collect.py

This worker listens for a start command and then continuously loops through all markers from the repository, gets their peak values from the instrument, and updates the repository with the new peak data.
