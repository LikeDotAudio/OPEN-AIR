🏷️ Composite Horizontal Dial Value

📖 Description & Purpose

File Level

composite_horizontal_dial_value/composite_horizontal_dial_value.py

A composite widget providing a horizontal fader and a dial for coarse/fine control. Refactored for a grid-based 3-column architecture: Column 0: Label (Row 0), Horizontal Fader (Row 1) (60%) Column 1: Knob (Span Rows 0-1) (20%) Column 2: Value Entry (Row 0), Units (Row 1) (20%)

Author: Anthony Peter Kuzub Version 20260307.Grid.4
