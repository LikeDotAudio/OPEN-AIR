📖 Description & Purpose

File Level

managers/Display/parser/widget_schema_normalizer.py

A standalone normalizer that translates "Universal Rhyme" schema into the flat schema expected by concrete widget creators. Decoupled from DynamicGuiBuilder inheritance.
