Bug Report - 2026-04-03 00:15:00

Issues

This report details the resolution of an AttributeError in the BallisticsEngine Python wrapper during testing.

Root Causes & Resolutions

1. Missing Method Call in Rust Wrapper

  • Issue: ‘'builtins.BallisticsEngine’ object has no attribute 'get_overload_fade_factor'(and previouslyoverload_fademissing).
  • **Root Cause**: The Python wrapperoaGuiElements/Core/metering/meter_bar/Core/ballistics.pywas attempting to call a methodself.rust_engine.get_overload_fade_factor()to retrieve the overload fade value. However, the Rust core implementation (oaMeteringEngine_rs) exposes this value as a direct property via a#[getter], not as a callable method.
  • **Resolution**: Updated the Python wrapper's properties (overload_fade_factorandoverload_fade) to correctly access the value as a property (self.rust_engine.overload_fade_factor`) rather than executing it as a method.

Affected Modules

  • oaGuiElements (Ballistics Engine Tests)

Verification

The unit tests (oaGuiElements/Tests/metering/test_rust_ballistics.py) were re-run manually via the Python unittest module and successfully passed, confirming the wrapper now correctly accesses the underlying Rust struct properties.
