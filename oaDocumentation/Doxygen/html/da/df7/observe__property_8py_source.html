6# /**
7# * Observe a property in an object.
8# *
9# * The callback function is called when a property value or change is received. In
10# * that case the callback is called with the arguments `true, value, changeIndex`. When an
11# * error occurs, e.g. when fetching the initial property value using the corresponding
12# * getter, the callback is called with arguments `false, Error`.
13# *
14# * The meaning of the changeIndex argument is meaningful in situations where a property has
15# * associated min and max value. In that situation the value received by the callback is
16# * the return value of the getter, which is an instance of Arguments. When either the property
17# * itself or min/max changes, the changeIndex will be the corresponding index in the arguments
18# * list. If the property has no min and max or when the initial value is returned from the
19# * getter, the value of changeIndex is undefined.

21# * @param {ObjectBase} o The remote object.
