Bug Report: Graphing Mapping and VISA Discovery Errors

Date: 2026-03-16 01:10:00 Priority: 1 (Critical/Crash) Impact:

  1. UI crashed due to missing graphing components mapping during bootstrap.
  2. Background core service crashed during VISA device discovery due to a missing/misnamed module import, followed by a circular dependency error upon fixing.

Issue

  1. A ‘Batch Processing Error: Unknown functional widget: 'plot_widget’occurred becauseplot_widget(andbar_graph) were not defined infactory_mapping.py.
  2. ABatch Processing Error: Unknown functional widget: 'OcaFold'occurred in spectrum layouts.
  3. ANameError: name 'manager_visa_Search' is not definedcrashed thediscovery_orchestratorworker thread when attempting to probe devices.
  4. AnImportError<tt>(circular dependency) surfaced betweenmanagers/Visa_Fleet/__init__.pyandworkers/discovery_agents/discovery_orchestrator.pyduring the fix for theNameError.
  5. AnImportErrorinShowtime.py(formerlygui_Showtime.py) due to a broken internal reference tooaGuiShowtime.Core.showtime_tab`.

Root Cause

  1. During the major UI decoupling and widget factory refactoring, the graphing widgets were not re-added to the core mapping table (factory_mapping.py), leaving the builder unable to resolve plot_widget and bar_graph.
  2. OcaFold mapping was missing from the factory.
  3. The recent file renaming/overhaul left discovery_orchestrator.py calling manager_visa_Search while importing it under the new module name visa_Search.
  4. managers/Visa_Fleet/__init__.py imported DiscoveryOrchestrator, creating a loop since discovery_orchestrator.py imports heavily from managers/Visa_Fleet.
  5. The showtime_ prefix removal refactor was incomplete, leaving internal imports referencing the old module names.

Resolution

  1. Added "plot_widget" and "bar_graph" to managers/Display/factory/core/factory_mapping.py, wiring them to PlotWidgetAdapterMixin inside the graphing widget folder.
  2. Added "OcaFold" mapping to factory_mapping.py.
  3. Updated the import in discovery_orchestrator.py to from oaComProtocols.oaComVisa.Visa_Fleet import visa_Search as manager_visa_Search to align with the rest of the file's usage.
  4. Removed the circular import of DiscoveryOrchestrator from managers/Visa_Fleet/__init__.py.
  5. Updated oaGui/Assets/right_50/bottom_90/2_monitors/23_Showtime/Showtime.py to correctly import ShowtimeTab from oaGuiShowtime.Core.tab.

Verification

  • Validated via python execution (‘python3 -c "import sys; sys.path.append(&rsquo;.'); from oaComProtocols.oaComVisa.discovery_orchestrator import DiscoveryOrchestrator") that the class successfully initializes and no longer triggers a circularImportErrororNameError`.
  • Verified the factory mapping paths logically resolve to the correct module.
