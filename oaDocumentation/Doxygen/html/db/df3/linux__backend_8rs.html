Language List The list of language tags that the device supports.

e.g. "es" Global Spanish.

When defined in-line, the keys shall be patterned on those defined at https://www.mesaonline.org/language-metadata-table with "example" substituted by "smpte2138".

In-line definition example: { "en": "Hello", // global English "es": "Hola", // global Spanish "fr": "Bonjour", // global French "en-CA": "Eh?", // Canadian English },

LanguagePack referencing example: { "$key": "greeting" }

And when defined by reference to a language pack the $key value is used to provide a look-up into the supported LanguagePack(s) e.g. $key = "greeting" could index to "Hello", "Hola" or "Bonjour" depending on which LanguagePack was active in the client. In-line language definition
