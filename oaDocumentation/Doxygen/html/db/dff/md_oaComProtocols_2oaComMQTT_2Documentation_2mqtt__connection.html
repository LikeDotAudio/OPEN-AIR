🏷️ Mqtt Connection Manager

📖 Description & Purpose

File Level

mqtt/mqtt_connection_manager.py

Manages the singleton MQTT client connection using aiomqtt (asyncio wrapper for paho). Bridges the async MQTT loop with the synchronous Tkinter application using a background thread.

Author: Anthony Peter Kuzub Version 20260218.AioMqtt.2
