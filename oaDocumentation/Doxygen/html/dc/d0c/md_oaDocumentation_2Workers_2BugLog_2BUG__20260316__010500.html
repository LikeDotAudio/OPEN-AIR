Bug Report: ModuleNotFoundError after Widget Migration

Date: 2026-03-16 01:05:00 Priority: 1 (Critical/Crash) Impact: Total application failure during UI bootstrap.

Issue

A ‘ModuleNotFoundError: No module named 'oaGui.panels’occurred, along with dozens of other broken imports, following the migration of widget directories toworkers/builder/widgets/`.

Root Cause

The refactoring that moved widget folders into categorical sub-containers (e.g., widgets/buttons/, widgets/faders/) was completed, but not all import statements and string-based module paths in the FactoryMapping were updated to reflect the new structure.

Resolution

Executed a comprehensive automated update of the codebase using a Python script to remap all oaGui.<widget> imports to their new oaGuiElements.<category>.<widget> locations. This included:

  1. Updating managers/Display/factory/core/factory_mapping.py lazy-load strings.
  2. Updating workers/builder/core/background.py.
  3. Updating dozens of inter-widget dependencies and mixins.
