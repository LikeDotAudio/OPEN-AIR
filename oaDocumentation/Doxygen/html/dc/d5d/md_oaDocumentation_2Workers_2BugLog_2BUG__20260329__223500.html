Bug Report: BUG_20260329_223500

Issue

A TypeError was reported during dynamic GUI building: ‘TypeError: BuilderArrayCreator.make_array() got multiple values for argument 'context’`

Root Cause

The make_array method in oaGui/Core/array/array.py was decorated with @staticmethod but the GuiWidgetFactory was calling it as an instance method, passing builder_instance as the first argument. This caused all positional arguments to shift, resulting in the config_data argument being assigned to the context parameter, and then the explicit context=context keyword argument causing a conflict.

Resolution

  1. Refactored make_array: Removed the @staticmethod decorator and added self as the first parameter to correctly consume the builder_instance passed by the factory.
  2. Standardized Factory Pattern: Added a static make method to BuilderArrayCreator to follow the project's preferred factory pattern.
  3. Updated Factory Mapping: Updated oaGui/Core/factory/Core/factory_mapping.py to use the make method for OcaArray and related identifiers.

Verification

  1. Verified that the argument signature now correctly handles the builder_instance as self.
  2. The self._create_dynamic_widgets call now correctly refers to the DynamicGuiBuilder instance.
