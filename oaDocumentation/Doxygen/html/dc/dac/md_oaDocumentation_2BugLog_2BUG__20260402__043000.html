Bug Report - 2026-04-02 04:30:00

Issues Resolved

1. CRITICAL: `ImportError` for `BlueprintParser`

  • Module: `oaGui.FileReaders.blueprint_loader`
  • Root Cause: Name collision between the `oablueprintparser_rs` package and its underlying shared object module. The `__init__.py` wrapper failed to correctly export `BlueprintParser`.
  • Resolution: Updated all import calls to use the direct sub-module path: `from oablueprintparser_rs.oablueprintparser_rs import BlueprintParser`.

2. CRITICAL: `TypeError` in State Cache Saver

  • Module: `oaStateCache.Core.cache_save_engine`
  • Root Cause: The Rust `StateRegistryCore` object was being passed directly to the Rust `DiskFlusher.flush_async`, which expects a Python `PyDict`. PyO3 cannot auto-coerce custom Rust classes to `PyDict`.
  • Resolution: Added explicit `to_dict()` conversion logic in the save worker loop before passing data to the flusher.

3. HIGH: `IndentationError` in OSC Dashboard

  • File: `oaGui/Assets/Assets/right_50/bottom_90/55_OSC/gui_OSC.py`
  • Root Cause: Misaligned indentation on line 37 (body of an `if` statement).
  • Resolution: Normalized indentation to 4 spaces.
