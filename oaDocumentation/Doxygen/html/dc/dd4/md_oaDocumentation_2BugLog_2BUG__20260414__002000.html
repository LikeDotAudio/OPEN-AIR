🏷️ BUG REPORT: [GUI-NMOS] Threading Lifecycle Mismatch (RuntimeError)

ID: BUG_20260414_002000 Priority: 1 Status: RESOLVED

📖 Description

Background monitor threads in the NMOS Connection and WebSocket GUI components were calling self.after() before the Tkinter main loop started or after the widget was destroyed, causing a RuntimeError: main thread is not in main loop.

🛠️ Root Cause

Race condition between background polling threads and the Tkinter event loop lifecycle.

🚀 Fix Action

  1. Added winfo_exists() checks before scheduling UI updates.
  2. Wrapped self.after() calls in try/except blocks to catch RuntimeError and TclError.
  3. Updated monitor loops to terminate gracefully if the UI is no longer available.

✅ Verification

Verified syntax and compilation. The guards prevent the reported crash during module initialization and shutdown.
