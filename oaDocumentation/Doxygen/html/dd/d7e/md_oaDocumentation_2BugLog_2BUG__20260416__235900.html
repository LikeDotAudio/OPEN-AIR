Bug Log: 20260416_235900

Description

High-frequency crashes and visual feedback failures during drag-and-drop operations in the WYSIWYG editor.

Error Clusters

  • Cluster A: Canvas Stacking Collision: TclError: wrong # args when calling raise() on a Canvas widget.
  • Cluster B: Ghost Overlay Displacement: The green insertion line was invisible due to incorrect coordinate offsets.
  • Cluster C: Drop Target Path Resolution: Elements were being added to the state but not appearing because they were assigned to invalid JSON branches.

Action Taken

  1. InteractiveLayout:
    • Switched self.ghost_overlay.tkraise() to tk.Widget.tkraise(self.ghost_overlay) to resolve shadowing conflict.
    • Corrected place() offsets for the interaction layer.
  2. FocusManager:
    • Refined find_drop_target_at to use winfo_rootx/y relative to the designers origin.
    • Enhanced insertion path resolution to support OcaContainer, OcaBlock, and OcaTable nested fields.
  3. GrabBagView:
    • Renamed all "Add" buttons to PLACE.

Verification Results

  • wrong # args error resolved.
  • Green insertion line confirmed visible and correctly aligned with target widgets.
  • Components placed via drag-and-drop now appear instantly in the interactive layout.
