8# A matrix is a rectangular array of identical objects ("**members**") that is
9# coordinate addressable and has sets of common input and output ports. The
10# matrix host does not instantiate these objects, but instead mediates the
11# coordinate addressing, implements the common input and output ports, and
12# provdes certain other aggregate functions. Matrix members may be workers
13# (including blocks), or agents. All members of a matrix must be of the same
14# class. No object may belong to more than one matrix at a time. No object may
15# appear more than once in a given matrix. The complete model of an OCA matrix
16# consists of: 1. One instance of **OcaMatrix.** 2. **(N x M) members**, where
17# each member is an instance of a worker or agent class. For any given matrix,
18# this class must be the same for all members, and is referred to as the
19# **member class.** Members are sometimes referred to as **cells** of the
20# matrix. 3. One additional instance of the member class, called the **matrix
21# proxy.** Thus, the **OcaMatrix** instance is a container for the
22# two-dimensional collection of its members. Once a matrix is set up, the
23# controller may get and set member properties by the following procedures:
24# **Get** To get a property value of member (x :sub:`1`, y :sub:`1`): 1.
25# Controller calls **OcaMatrix.SetXY(x1, y1)**. This action: - locks the
26# **OcaMatrix** instance, and - posts x :sub:`1` and y :sub:`1` as coordinates
27# of the object whose property value is to be retrieved. 2. Controller calls the
28# matrix proxy's **Get** method for the property value desired. This action
29# causes the **OcaMatrix** instance to: - decode the posted x :sub:`1` and y
30# :sub:`1` values into a member ONo. - call the given **Get** method for the
31# object identified by the decoded ONo. - aggregate the **OcaResult** from each
32# **Get** call into a consolidated **OcaResult**. - unlock the **OcaMatrix**
33# instance. - return the consolidated **OcaResult** to the controller. **Set**
34# ** **To set a property value of member (x :sub:`1`, y :sub:`1`), or of row (0,
35# y :sub:`1`) or column (x :sub:`1`, 0) or whole matrix (0,0) 1. Controller
36# calls **OcaMatrix.SetXY(x1, y1)**. This action: - locks the **OcaMatrix**
37# instance, and - posts x :sub:`1` and y :sub:`1` as coordinates of the object
38# whose property value is to be changed. 2. Controller calls the matrix proxy's
39# **Set** method for the target property. This action causes the **OcaMatrix**
40# instance to: - decode the posted x :sub:`1` and y :sub:`1` values into a list
41# of target member ONos, as follows: If x :sub:`1` ``>`` 0 and y :sub:`1` ``>``
42# 0, the list will be the single ONo of the addressed cell. If x :sub:`1` = 0
43# and y :sub:`1` ``>`` 0, the list will be the list of ONos of the cells in row
44# y :sub:`1` . If x :sub:`1` ``>`` 0 and y :sub:`1` = 0, the list will be the
45# list of ONos of the cells in column x :sub:`1`. If x :sub:`1` = 0 and y
46# :sub:`1` = 0, the list will be the list of ONos of all cells of the matrix. -
47# call the given **Set** method for each target member in the ONo list. -
48# aggregate the **OcaResult** from each **Set** call into a consolidated
49# **OcaResult**. - unlock the **OcaMatrix** instance.
