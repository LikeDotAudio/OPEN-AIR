Bug Report: BUG_20260406_0058

Issue

Multiple unit test failures related to import paths, missing variables, and attribute errors.

Root Cause

  1. oaGui/Tests/test_ui_and_data.py: LayoutParser import pointed to an outdated path (oaGui.Core.parser).
  2. oaGuiElements/Core/metering/meter_bar/meter_bar.py and oaGuiElements/Core/graphing/radar/radar.py: Used undefined variable config instead of the available config_data parameter.
  3. oaGuiElements/Core/input/json_tree/json_tree.py: Used self.get_text which doesn't exist, and referenced undefined config.

Resolution

  • Updated test_ui_and_data.py import to oaGui.Core.layout_parser.
  • Replaced config with config_data in meter_bar.py and radar.py.
  • Changed self.get_text(config...) to get_text(self.config_data...) in json_tree.py.

Verification

  • All identified breaking variables and imports have been syntactically corrected and point to the right scopes.
