Bug Log: BUG_20260315_232600 - Protocol Bridge & Telemetry Suspension (AES70, OSC, Visibility)

Issue

The AES70 (OCA), OSC features, and Window Visibility telemetry were causing data structure issues or redundant network traffic. These were deemed not ready for the current architecture phase, specifically during the transition to a centralized MQTT state mirror.

Root Cause

  • AES70: Intercepting and re-wrapping already-enveloped data.
  • OSC: Potential source of un-architected state traffic.
  • Visibility Snitch: High-frequency MQTT events triggered by UI interactions (tab switching, resizing) causing log noise and potential race conditions in the state cache.

Resolution

  1. Configuration: Modified config.ini:
    • scan_aes70 = False
    • aes70_debug_enable = False
    • scan_osc = False
    • osc_debug_enable = False
  2. Launcher Suppression: In managers/launcher.py:
    • Commented out the AES70Manager launch.
    • Commented out the OSCManager launch.
  3. Telemetry Suppression: In managers/Display/telemetry/visibility_snitch/visibility_snitch.py:
    • Commented out the _publish_visibility logic ("On Ice").
  4. UI Safety: UI components for these protocols safely handle the absence of their respective managers.

Verification

  • Verification Script: Manual check and launcher verification.
  • Results:
    • scan_aes70 and scan_osc confirmed False in config.ini.
    • manager_launcher.py confirmed to have both managers commented out.
    • visibility_snitch.py publishing confirmed commented out.

Status

CLOSED / SUSPENDED (Awaiting re-architecture)
