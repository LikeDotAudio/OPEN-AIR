Bug Report - 2026-04-02 02:00:00

Issues

This report details a batch of bugs fixed on 2026-04-02. The issues involved a TypeError when persisting the state cache using the Rust engine, and a persistent ImportError preventing the BlueprintParser from being loaded from its compiled Rust extension.

Root Causes & Resolutions

1. TypeError in CacheSaveEngine

  • Issue: ‘TypeError: argument 'data’: 'StateRegistryCore' object cannot be converted to 'PyDict'inoaStateCache/Core/cache_save_engine.py.
  • **Root Cause**: The_workermethod inCacheSaveEngineattempted to pass the RustStateRegistryCoreobject (self.cache) directly toflusher_instance.flush_async(). PyO3 could not automatically coerce this custom Rust object into a Python dictionary (PyDict).
  • **Resolution**: Modified the code to check ifself.cachehas ato_dictmethod (which the Rust implementation provides). If so, it callsself.cache.to_dict()to generate a standard dictionary before passing it to the flusher. Otherwise, it falls back todict(self.cache)`.

2. ImportError for BlueprintParser

  • Issue: ‘ImportError: cannot import name 'BlueprintParser’ from 'oablueprintparser_rs'inoaGui/FileReaders/json_blueprint_reader.pyandoaGui/FileReaders/oaBlueprintParser_rs/compiler_hook.py.
  • **Root Cause**: Thematurindevelop command generated an__init__.pywrapper for theoablueprintparser_rsPython package that failed to correctly expose theBlueprintParserclass from the underlying compiled.soextension (namedoablueprintparser_rs.cpython...so). The class was successfully compiled but hidden within theoablueprintparser_rs.oablueprintparser_rsnamespace.
  • **Resolution**: Updated all import statements acrossjson_blueprint_reader.pyandcompiler_hook.pyto bypass the generated__init__.pywrapper and import the class directly from the compiled shared object:from oablueprintparser_rs.oablueprintparser_rs import BlueprintParser`.

Verification

The fixes have been applied and the application should now successfully save the state cache to disk and instantiate the BlueprintParser during the GUI bootstrap sequence without raising exceptions.
