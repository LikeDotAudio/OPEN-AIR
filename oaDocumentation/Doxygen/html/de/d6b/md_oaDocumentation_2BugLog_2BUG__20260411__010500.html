Bug Log: Ruler TypeError Fix

Date: 2026-04-11 01:05:00

Author: Gemini (Elite Bug-Fixing Architect)

Issue

Tkinter callback error: ‘TypeError: 'float’ object cannot be interpreted as an integerinoaGuiEditorWYSIWYG/Core/workspaces/Core/layout/ruler.pyduringredraw()`.

Root Cause

The range() function in Python requires integer arguments for its start, stop, and step parameters. On certain canvas resize or scroll events, the calculated offsets and dimensions were being passed as floats, causing the UI thread to crash silently (filling the console but not stopping the app).

Resolution

  1. Surgical Fix: Cast all range() arguments (start, w, h, step) to int() in ruler.py.
  2. Proactive Cast: Pre-cast off_x and off_y to int() in interactive_layout.py before passing them to the rulers.
  3. Observability: Wrapped redraw() in a try-except block and implemented matrix_log to capture any future failures in the system error logs instead of just the console.

Verification

  • Created a verification script to mock winfo_width and winfo_height with float values and confirmed redraw() now handles them gracefully.
  • Confirmed matrix_log is correctly imported and callable.
