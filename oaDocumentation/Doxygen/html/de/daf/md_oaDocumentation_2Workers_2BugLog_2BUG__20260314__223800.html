Bug Report: ModuleNotFoundError in manager_launcher.py

Date: 2026-03-14 22:38:00
Priority: 1 (Critical/Crash)
Status: Resolved
Module: managers/launcher.py

Issue

The CORE partition failed to start with the following error: ‘ModuleNotFoundError: No module named 'workers’ This occurred at line 24 ofmanagers/launcher.py` during its initial imports.

Root Cause

manager_launcher.py relied on the caller to set up the Python sys.path to include the project root. While open_air_core.py performs this setup, if manager_launcher.py is imported directly in a context where the current working directory or the root search path is not properly configured (e.g., during direct debugging or certain multi-process spawn scenarios), it fails to locate the top-level workers package.

Resolution

Added the sys.path boilerplate to the top of managers/launcher.py. This logic dynamically resolves the project root relative to the file's own location and ensures it is present in the sys.path before any relative or absolute package imports are executed.

Verification Evidence

  1. Reproduction: A script reproduce_path_bug.py was created to simulate importing manager_launcher.py from within the managers/ directory without prior path setup.
  2. Fix Verification: The same script now reports a successful import, confirming that manager_launcher.py can independently resolve its dependencies.
  3. Consistency: This fix aligns manager_launcher.py with the robust initialization patterns already used in open_air_core.py and open_air_ui.py.

Impact

Improves system-wide stability and developer ergonomics by making the partition launcher scripts more resilient to different execution environments and directory contexts.
