BugLog Entry: 20260409_004800

Issue Summary

Tests for oaAudioMixer failed with ‘ModuleNotFoundError: No module named 'oaaudiomixer_rs’`. This occurred even after the module was manually compiled, because the test runner was likely executing in a context where the site-packages or environment paths were not synchronized, and the test script itself lacked the automatic compilation hook.

Root Cause Analysis

The test file oaAudioMixer/Tests/test_mixer_smoke.py imported oaaudiomixer_rs directly without ensuring the module was compiled and installed in the current environment. While Entry.py included the ensure_compiled() hook, direct execution of the test bypassed this safety check.

Resolution

Modified oaAudioMixer/Tests/test_mixer_smoke.py to include the ensure_compiled() hook call from the module's compiler_hook.py before attempting to import the native extension. This ensures that the test remains self-sufficient and reliable across different execution environments.
