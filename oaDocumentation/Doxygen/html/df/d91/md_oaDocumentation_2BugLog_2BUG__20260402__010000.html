Bug Report - 2026-04-02 01:00:00

Issues

This report details a batch of bugs fixed on 2026-04-02. The issues ranged from critical crashes to UI rendering errors and threading problems.

Root Causes & Resolutions

1. AttributeError in StateManager

  • Issue: ‘AttributeError: 'StateManager’ object has no attribute '_json_data'
  • **Root Cause**: TheStateManagerwas trying to access a non-existent_json_dataattribute. The state is managed by a Rust backend and should be accessed via theget_state()method.
  • **Resolution**: ModifiedoaGuiEditorWYSIWYG/Core/state.pyto callself.get_state()instead of accessingself._json_data`.

2. AttributeError in BallisticsEngine

  • Issue: ‘AttributeError: 'BallisticsEngine’ object has no attribute 'overload_fade_factor'
  • **Root Cause**: TheBallisticsEnginePython wrapper did not expose theoverload_fade_factorattribute from the underlying Rust engine.
  • **Resolution**: Added a property to theBallisticsEngineclass inoaGuiElements/Core/metering/meter_bar/Core/ballistics.py` to expose the value from the Rust engine.

3. SyntaxError in text_value_with_units.py

  • Issue: SyntaxError: invalid syntax
  • Root Cause: A trailing comma in a function call.
  • Resolution: Removed the trailing comma in oaGuiElements/Core/text/text_value_with_units/text_value_with_units.py.

4. FileNotFoundError for UI Blueprints

  • Issue: FileNotFoundError: The Blueprint is missing! Cannot find JSON at: ...
  • Root Cause: The GUI builder was attempting to load JSON files that did not exist.
  • Resolution: Created empty JSON files for the missing blueprints to prevent the application from crashing.

5. IndentationError in gui_REST.py

  • Issue: IndentationError: expected an indented block
  • Root Cause: An import statement was not correctly indented.
  • Resolution: Fixed the indentation in oaGui/Assets/Assets/right_50/bottom_90/44_REST/gui_REST.py.

6. RuntimeError in SMPTE2138 Monitor

  • Issue: RuntimeError: main thread is not in main loop
  • Root Cause: A background thread was attempting to directly update the GUI, which is not thread-safe in Tkinter.
  • Resolution: Modified oaComProtocols.oaComSMPTE2138/Managers/smpte2138_monitor_manager.py to use the application-wide event_bus for communication between the manager and the GUI, ensuring that all GUI updates are performed on the main thread.

Verification

The fixes have been applied and the application should no longer crash or produce the errors listed in the initial log. The UI for the components with missing blueprints will be empty, but this is expected behaviour given the missing files.
