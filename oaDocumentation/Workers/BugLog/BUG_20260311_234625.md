# Bug Log: BUG_20260311_234625

## **Issue**
The `config.ini` file is not being created when `OpenAir.py` is run, especially after a "Fresh Start" or manual deletion.

## **Root Cause**
The `Config` singleton's `read_config` method relied on `GLOBAL_PROJECT_ROOT` from `path_initializer.py`. However, many modules import `Config` and call `get_instance()` at the global scope. If these modules are imported before `OpenAir.py` explicitly initializes paths, `read_config` might fail silently or encounter uninitialized variables. Additionally, the `FreshStart.toml` and `GitCommit.toml` commands were missing explicit instructions to purge local git objects, which the user requested.

## **Investigation**
1.  **Grep Search**: Identified all references to `config.ini` and `get_instance()`.
2.  **Empirical Reproduction**: Attempted to reproduce by deleting `config.ini` and running `OpenAir.py`. While it worked in most cases, the potential for race conditions or out-of-order execution in global scope imports was identified as a significant risk.
3.  **Code Review**: Noticed that `read_config` did not have explicit error handling around the creation of the default config file, leading to potential silent failures.

## **Resolution**
1.  **Modified `managers/configini/config_reader.py`**:
    - Added explicit path initialization check (`if not GLOBAL_PROJECT_ROOT: initialize_paths()`) inside `read_config` to ensure it always has valid path context.
    - Wrapped `create_default_config_ini` and `config.read` in `try-except` blocks with descriptive logging.
    - Improved log messages to use `LOCAL_DEBUG` flags and standard `loguru` patterns.
2.  **Modified `.gemini/commands/FreshStart.toml`**:
    - Added `rm -rf ../.git/objects` to the cleanup logic.
3.  **Modified `.gemini/commands/GitCommit.toml`**:
    - Added `rm -rf ../.git/objects` to the purge logic.
4.  **Updated Documentation**:
    - Updated `assets/Documentation/CHANGELOG.md` with timestamped entries.
    - Updated `assets/Documentation/MAP.txt` with new file structures and line counts.

## **Verification**
1.  **Manual Test**: Deleted `config.ini` and ran `OpenAir.py`. Verified that `config.ini` was recreated and `Installation/Setup.py` was triggered.
2.  **Command Test**: Verified that `FreshStart` and `GitCommit` logic now includes the `.git/objects` deletion.
3.  **Import Test**: Verified that importing `Config` early in a script now correctly triggers path initialization and file recreation if necessary.
