# Bug Report: Critical Stability & Permission Hardening
Date: 2026-03-15 01:45:00

## 🔍 Phase 1: The Log-Hunting Strategy (Research)

1.  **Hard Filtering (Signal vs. Noise)**:
    - `PermissionError: [Errno 1] Operation not permitted` in `managers/PTP/ptp.py`.
    - `AttributeError: 'StateMirrorEngine' object has no attribute 'start_queue_processing'` in `managers/Display/core/bootstrap_sequence.py`.
    - `WARNING | FAILED (IDN Query Error)` in `oaComProtocols.oaComVisa.Visa_Fleet.visa_Search`.

2.  **The 'Last Good Action' Backtrace**:
    - **PTP**: Triggered by Scapy's `sniff` method in `_run_sniffer`. This requires `AF_PACKET` raw sockets, which Linux restricts to root/sudo.
    - **UI**: Triggered at the end of the `bootstrap_sequence.py` in the `_finish` callback. It attempted to call a non-existent public method on the `StateMirrorEngine`.

3.  **Visual Domain Grepping**:
    - `[CORE]` -> PTP Manager, VISA Search.
    - `[UI]` -> Bootstrap Sequence.

4.  **Context Retention**:
    - `managers/PTP/ptp.py`
    - `managers/Display/core/bootstrap_sequence.py`
    - `workers/logic/state_mirror_engine.py` (Implementation of the engine)
    - `managers/Visa_Fleet/visa_utility_parser.py` (Centralized timeout)

## 📋 Phase 2: Prioritized Bug Task List

| Priority | Task | Module | Impact |
| :--- | :--- | :--- | :--- |
| 1 | `AttributeError` in Bootstrap | `bootstrap_sequence.py` | UI fails to initialize properly, blocking application start. |
| 1 | `PermissionError` in PTP | `ptp_manager.py` | PTP monitoring fails without root privileges, causing log spam. |
| 2 | IDN Query Warnings | `visa_utility_parser.py` | Potential incomplete fleet discovery for slow devices. |

## 🛠️ Phase 3: Best Practice Solutions & Strategy

1.  **UI Fix**: Replaced the non-existent `start_queue_processing()` call with the correct internal `_schedule_queue_processing()` in `bootstrap_sequence.py`.
2.  **PTP Fix**: Added a specific `except PermissionError` block to catch the `AF_PACKET` failure. Provided a clear instructional warning instead of a raw traceback.
3.  **VISA Fix**: Increased `VISA_TIMEOUT` from 2500ms to 5000ms to allow more headroom for legacy or slow network-based instruments during the fleet discovery scan.
