# Bug Report: NameError in LyricManager

**Date:** 2026-03-16 00:45:00
**Priority:** 1 (Critical/Crash)
**Impact:** EngineGuiDisplay failure during splash screen initialization.

## Issue
A `NameError: name 'lyrics_data' is not defined` occurred in `workers/splash_screen/core/lyric.py` on line 14.

## Root Cause
The `LyricManager._load` method was attempting to access a variable named `lyrics_data` that was neither imported nor defined. It was trying to use a `getattr(lyrics_data, ...)` call while the import statement was `from .. import lyrics`.

## Resolution
Modified `workers/splash_screen/core/lyric.py` to correctly import the `lyrics` list from the `lyrics` module and assign it to `self.lyrics`. Added type checking and robust error handling to prevent future crashes.
