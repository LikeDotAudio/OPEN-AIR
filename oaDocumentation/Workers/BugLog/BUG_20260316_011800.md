# Bug Report: ImportError in VisaFleetManager (Circular Dependency Refactor)

**Date:** 2026-03-16 01:18:00
**Priority:** 1 (Critical/Crash)
**Impact:** Total application failure during Core Service launch.

## Issue
An `ImportError: cannot import name 'DiscoveryOrchestrator' from 'oaComVisa.Visa_Fleet'` occurred in `managers/Visa_Fleet/visa_fleet.py`.

## Root Cause
To resolve a circular dependency between `DiscoveryOrchestrator` and `oaComVisa.Visa_Fleet`, the import of `DiscoveryOrchestrator` was removed from `managers/Visa_Fleet/__init__.py`. However, `visa_fleet.py` was still attempting to import it from the package level (`from oaComVisa.Visa_Fleet import DiscoveryOrchestrator`) instead of from its source in `oaComVisa`.

## Resolution
Modified `managers/Visa_Fleet/visa_fleet.py` to import `DiscoveryOrchestrator` directly from its actual location:
`from oaComVisa.discovery_orchestrator import DiscoveryOrchestrator`

## Verification
Ran a Python reproduction script that imports `VisaFleetManager`:
- **Output:** `VisaFleetManager Success`
- **Log trace:** Confirmed successful initialization of the manager and its nested orchestrator.
