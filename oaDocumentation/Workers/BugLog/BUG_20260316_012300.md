# Bug Report: UI Window Collapsing on Display Move

**Date:** 2026-03-16 01:23:00
**Priority:** 2 (High/Usability)
**Impact:** The user interface becomes unusable when moving the application between screens as it collapses into a thin strip.

## Issue
Moving the OPEN-AIR display from one screen to another causes the Tkinter window to spontaneously resize to a "thin strip," effectively making the GUI inaccessible.

## Root Cause
Lack of a defined minimum size for the root Tkinter window allowed the window manager to collapse the window during screen-transition events or dpi-change handshakes.

## Resolution
Modified `managers/Display/core/tab_physical_window.py` to call `root.minsize(800, 600)` during the root window initialization. This ensures that the window manager can never shrink the application below these functional dimensions.

## Verification
- **Test Script**: Verified via `root.minsize()` query that the dimensions are correctly registered by the Tcl interpreter.
- **Result**: `Root minsize: 800x600`
