# Bug Report: BUG_20260329_221500

## Issue
The `SnmpLog` UI widget was emitting high-velocity `print()` statements to the console whenever SNMP traffic was received, even when global debug modes were off.

## Root Cause
The `on_snmp_traffic()` callback and the `_find_snmp_manager()` method in `oaGui/Assets/Assets/right_50/bottom_90/11_SNMP/00_Log/snmp_log.py` used direct `print()` statements that were not gated by any debug flag.

## Resolution
1.  **Gating Logic**: Added `LOCAL_DEBUG = False` as a standard gate at the top of the file.
2.  **Surgical Fix**: Wrapped all `print()` statements in `if LOCAL_DEBUG:` blocks.
3.  **Standard Compliance**: Aligned the widget with the project's Zero-Cost Gates and local debug mandates.

## Verification
1.  Verified that `LOCAL_DEBUG` is set to `False` by default.
2.  Verified that all console-outputting code in the file is now conditional.
