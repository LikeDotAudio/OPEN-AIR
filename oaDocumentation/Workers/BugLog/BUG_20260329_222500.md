# Bug Report: BUG_20260329_222500

## Issue
A `ModuleNotFoundError` was reported when loading the Showtime module:
`ModuleNotFoundError: No module named 'oaGuiShowtime.Core.draw_bargraph'`

## Root Cause
The file `draw_bargraph.py` was correctly located in `oaGuiShowtime/Methods/` per project standards, but `oaGuiShowtime/Core/ui_mixin.py` was attempting a relative import from the `Core` directory.

## Resolution
Corrected the import in `oaGuiShowtime/Core/ui_mixin.py` from `from .draw_bargraph import create_bar_graph_image` to `from oaGuiShowtime.Methods.draw_bargraph import create_bar_graph_image`.

## Verification
Executed a python snippet to import `ShowtimeTab` from `oaGuiShowtime.Core.tab`, which confirmed that all dependent mixins (including `ui_mixin`) now load correctly.
Evidence: `Import Success` output from verification command.
