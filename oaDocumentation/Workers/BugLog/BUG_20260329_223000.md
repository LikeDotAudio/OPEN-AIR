# Bug Report: BUG_20260329_223000

## Issue
A `TypeError` was reported in the Command Router when attempting to create a direct splink:
`TypeError: ProtocolRouter.publish_splink() got an unexpected keyword argument 'source_val'`

## Root Cause
The `create_direct_splink` method in `oaGui/Assets/Assets/right_50/bottom_90/3_Command_Router/command_router.py` was calling `self.router.publish_splink()` with keyword arguments `source_val` and `dest_val`. However, the `ProtocolRouter.publish_splink()` method defined in `oaComBroker/Core/protocol_router/router.py` uses `s_val` and `d_val` as its argument names.

## Resolution
Modified `command_router.py` to use the correct keyword arguments (`s_val` and `d_val`) in the `publish_splink` call.

## Verification
1.  Verified the parameter names in `oaComBroker/Core/protocol_router/router.py`.
2.  Performed a syntax check using `py_compile` on the modified `command_router.py`.
