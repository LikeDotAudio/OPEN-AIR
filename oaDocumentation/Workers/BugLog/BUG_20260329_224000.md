# Bug Report: BUG_20260329_224000

## Issue
An `AttributeError` was reported during GUI construction:
`AttributeError: 'BuilderArrayCreator' object has no attribute '_create_dynamic_widgets'`

## Root Cause
In the previous refactor of `BuilderArrayCreator`, the code was updated to use `self._create_dynamic_widgets`. However, `self` in this context refers to an instance of `BuilderArrayCreator`, which does not implement `_create_dynamic_widgets`. This method is provided by the `DynamicGuiBuilder` (the `builder_instance`).

## Resolution
Modified `oaGui/Core/array/array.py` to correctly use the `builder_instance` variable (which holds the reference to `DynamicGuiBuilder`) to call `_create_dynamic_widgets`.

## Verification
1.  Verified that `builder_instance` is correctly resolved from the `context` or `kwargs`.
2.  Verified that the call to `_create_dynamic_widgets` now targets the correct object.
