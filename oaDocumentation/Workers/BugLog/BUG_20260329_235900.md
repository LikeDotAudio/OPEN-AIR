# Bug Report: BUG_20260329_235900

## Issue
1.  **Crash on Boot**: The application crashed with a `ValueError` during configuration parsing: `ValueError: Not a boolean: update_canvas, poll_buffer, heart_beat`.
2.  **Verbose Defaults**: The new debug matrix was defaulting to `True` for several components, causing console clutter on first run.
3.  **Missing Auto-Generation**: Missing `config.ini` files were generated without the `[DEBUG_MATRIX]` section.

## Root Cause
1.  **Type Mismatch**: The `_parse_debug_matrix` method in `config_reader.py` was iterating over all keys in the `[DEBUG_MATRIX]` section and applying `getboolean()` to them. This failed for `mute_functions` and `force_functions`, which are comma-separated strings.
2.  **Default Polarity**: `ConfigDefaults` and `config_builder.py` had some debug matrix toggles set to `True`.
3.  **Outdated Template**: `config_builder.py` had not been updated to include the new hierarchical logging schema.

## Resolution
1.  **Safe Parsing**: Updated `oaConfigurationManager/FileReaders/config_reader.py` to explicitly skip `mute_functions` and `force_functions` during boolean conversion.
2.  **Silent Defaults**: Set all debug matrix toggles to `False` in `ConfigDefaults`, `config_builder.py`, and the active `config.ini`.
3.  **Generator Update**: Integrated the `[DEBUG_MATRIX]` section into the `create_default_config_ini` logic in `oaConfigurationManager/Core/config_builder.py`.

## Verification
1.  Verified that the application now boots successfully without `ValueError`.
2.  Verified that `config.ini` is correctly updated with the new section.
3.  Confirmed that all debug logs are silenced by default as requested.
