# Bug Report: BUG_20260330_001500

## Issue
The testing module (`oaTests`) had "force debug on/off" buttons that performed blanket scans/replacements, which was fragile and did not align with the new Hierarchical Debug Matrix.

## Root Cause
Legacy implementation relied on overwriting `LOCAL_DEBUG` constants in source files instead of utilizing a centralized configuration.

## Resolution
1.  **Centralized Hub**: Created `oaTests/Managers/configIniEditor/manager.py` to handle direct manipulation of the `[DEBUG_MATRIX]` section in `config.ini`.
2.  **UI Modernization**: Updated `oaTests/Interface/left_panel.py` to remove the "FORCE DEBUG" buttons and replace them with a structured list of checkboxes for:
    - Master Switch
    - System Levels (COMMS, GUI, etc.)
    - Element Levels (MQTT, SNMP, etc.)
3.  **Event Integration**: Updated `oaTests/Interface/TestsUI.py` to handle `Checkbox.Changed` events and commit changes to disk immediately.

## Verification
1.  Manual UI audit confirms checkboxes load with correct initial values from `config.ini`.
2.  Toggling a checkbox (e.g., `chk_sys_comms`) correctly updates `config.ini` and logs the change to the TUI console.
3.  Legacy button handlers were successfully removed, and `TestsApp` launches without errors.
