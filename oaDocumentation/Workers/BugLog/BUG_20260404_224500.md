# Bug Log: BUG_20260404_224500
**Issue**: Redundant traceback logging and inconsistent shutdown calls in AsyncBootstrapEngine.
**Root Cause**: logger.exception was used with manual traceback.format_exc(), and one shutdown call bypassed the main thread queue.
**Resolution**: Cleaned up log calls and wrapped shutdown in root.after().
**Verification**: Verified with oaGui/Tests/test_bootstrap_sequence.py.
