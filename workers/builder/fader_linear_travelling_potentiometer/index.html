LTP: Linear Travelling Potentiometer - Anthony Kuzub (Anthony@Kuzub.com)

Controls:
Drag Handle: Adjust Linear Value (Volume/Level)
Ctrl + Drag Handle: Adjust Rotation (Pan/Param)
Freestyle Mode: Drag adjusts BOTH simultaneously.
Scroll: Fine-tune Linear | Ctrl + Scroll: Fine-tune Rotation
Mobile: Grab the fader with one finger and move a second left and right to adjust the potentiometer.
